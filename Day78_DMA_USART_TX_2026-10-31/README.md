## 程序怎样工作

`main.c` 初始化外设，配置DMA，随后用测试字符串和每行末尾的 `\r\n` 填充 `text`。

按K1后，`EXTI4_IRQHandler()` 使能USART1发送DMA请求并启动通道；DMA按请求搬运数据，USART负责串行输出。CPU仍在这个中断函数的 `while` 中检查 `DMA1_FLAG_TC4`。检测到标志后清标志、退出等待，再清外部中断挂起位。

**今天纠正的关键认识：DMA负责搬运，不代表这份代码中的CPU已经空闲。CPU仍在轮询“有没有搬完”。** 本次没有验证CPU同时执行其他任务，没有做HAL移植或非阻塞改写。

## 理解与自测记录

| 知识点 | 实际达到的程度 |
| --- | --- |
| CPU、DMA、USART分工 | 讨论后明确；“CPU空闲”纠正为“CPU正在检查有没有搬完” |
| 地址自增 | 明确内存递增、数据寄存器固定；关闭内存递增时可重复发送同一位置，如AAAAA |
| 字符串长度 | 明确 `sizeof("ABC")=4`；减1只是发送范围排除末尾 `'\0'`，没有删除结束符 |
| 100行长度 | `ABC\r\n` 重复100次为500字节，这道计算独立答对；不是本次中文字符串的实收字节数 |
| 数据宽度 | 16位×100单元=200字节，最初答400，经解释纠正；随后答对32位×100单元=400字节 |
| 方向与通道 | 讨论后明确PeripheralDST为外设目的地，DMA1_Channel4为DMA1的第4通道 |
| 优先级 | 已讨论DMA通道竞争时优先级的作用；不等同于CPU中断优先级，本次无多通道竞争实验 |
| `t`、`i` | `t`遍历buf并在换行后归0；`i`继续填充text |
| 回车、换行 | 最初把回车说成 `'\0'`，已纠正为 `'\r'`；换行为 `'\n'` |
| 普通模式与TC4 | 搬完停止、TC4表示DMA搬运完成、清标志不等于清数据，均经解释和巩固，不能全部写成无提示答对 |
| 两端宽度不同 | 补充了解STM32F103 DMA补零、截取规则，未做对应实验 |
