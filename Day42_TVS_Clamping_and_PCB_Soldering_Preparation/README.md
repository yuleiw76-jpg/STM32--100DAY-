## 二、二极管伏安特性曲线

二极管伏安特性曲线描述二极管两端电压变化时，电流如何变化。

- 正向偏置时，耗尽层变窄，正向电流随电压增加而快速上升；
- 硅二极管不是到 0.7 V 才突然导通，0.7 V 只是常用工程近似；
- 反向偏置时，耗尽层变宽，通常只有很小的反向漏电流；
- 达到击穿条件后，反向电流会迅速增大。

二极管是非线性器件，不能把它简单当成固定电阻或绝对的通断开关。

## 三、稳压二极管的反向连接

阳极 A、阴极 K 是二极管自身的端子名称，VCC 和 GND 是电路中的电位节点，不能说 VCC 是整个电路的阳极、GND 是整个电路的阴极。

为了让稳压二极管工作在反向击穿区，典型接法为：

```text
VCC → 阴极 K
GND → 阳极 A
```

此时阴极电位高于阳极，二极管处于反向偏置。稳压二极管用于持续稳压时必须配合限流电阻，防止击穿电流和功率超过额定范围。

## 四、TVS 的雪崩击穿过程

反向尖峰增大时，PN 结的耗尽层变宽，其中的电场强度不断增加。达到临界电场后，少数载流子被强电场加速并撞击晶格，产生新的电子和空穴；新载流子继续参与碰撞，最终形成雪崩倍增。

```text
反向尖峰升高
  → 耗尽层电场增强
  → 载流子被加速
  → 碰撞产生更多电子和空穴
  → 雪崩电流迅速增大
```

TVS 并不是凭空制造电流，而是通过雪崩过程提供一条能够通过大反向电流的低动态电阻通路。尖峰电流由尖峰来源提供。

## 五、TVS 如何实现电压钳位

TVS 本体与被保护的后级电路并联，线路和尖峰源本身的等效阻抗位于前方：

```text
尖峰来源 ── 线路/电源内阻 ──┬── 后级电路
                            │
                           TVS
                            │
                           GND
                            │
                      返回尖峰来源
```

正常电压下，TVS 基本截止，不影响后级供电。尖峰超过击穿条件后，TVS 迅速通过很大的反向电流：

```text
尖峰来源 → VCC 节点 → TVS → GND → 返回尖峰来源
```

大电流使线路、电源内阻或串联器件上的压降增加：

```text
U线路 = I_TVS × R线路
```

因此，多出来的尖峰电压主要落在线路和尖峰源的等效阻抗上，被保护节点则被限制在 TVS 的钳位电压附近。尖峰能量最终主要在 TVS 和线路阻抗中转化为热量。

GND 不是吸收能量的“垃圾桶”，而是电流返回尖峰来源的低电位通路。

## 六、TVS 不是精密稳压器

TVS 数据手册中需要区分：

| 参数 | 含义 |
| --- | --- |
| `VRWM` | 可长期承受且基本不导通的反向工作电压 |
| `VBR` | 开始明显反向击穿的电压 |
| `VC` | 指定浪涌电流下的钳位电压 |
| `IPP` | 指定脉冲条件下允许的峰值电流 |

通常满足：

```text
VRWM < VBR < VC
```

因此，标称 5 V 的 TVS 不代表会把节点精确固定在 5.0 V。TVS 的作用是把原本更高的瞬时尖峰限制在相对较低的范围，而不是代替电源稳压器。

TVS 适合处理短时间浪涌。如果持续承受过压，功率和结温会不断升高，最终仍可能烧毁，因此持续过压还需要保险丝、限流、过压关断等措施。

## 七、PCB 布局与后续验证

TVS 应尽量靠近电源接口或尖峰进入的位置，连接 VCC 和 GND 的走线应短而宽，以减小寄生电感和回流路径面积。

收到裸板后的验证顺序计划为：

```text
检查板框、钻孔、焊盘和阻焊
  → 焊接电源部分
  → 断电测量 VCC 与 GND 是否短路
  → 限流输入 5 V
  → 测量 AMS1117 输出是否为 3.3 V
  → 断电后焊接 MCU 与外围器件
  → 再次检查短路和极性
  → SWD 下载 LED 测试程序
```
