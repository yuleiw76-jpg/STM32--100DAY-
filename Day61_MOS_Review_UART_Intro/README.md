## 一、MOS 部分：本日补学的理论

- **低边 N-MOS 的主电流路径**：开通时，常规电流从电源正端经负载、MOS 漏极与源极回到地。栅极是控制端，不是负载主电流的通路。
- **栅极充放电与 PWM**：栅极近似电容性负载；每次开关都要充放电。PWM 频率和栅极电荷会影响驱动负担，不能只看稳态栅极电流。
- **3.3 V 驱动选管**：不能用 `VGS(th)` 代替充分导通的依据。应核对器件在实际 `VGS` 条件下给出的 `RDS(on)`，并结合电流、损耗和温升判断。
- **感性负载关断**：电感电流不能瞬间消失，必须考虑适合实际拓扑的续流路径和保护。
- **体二极管与半桥**：N-MOS 的体二极管具有固定方向，关断不等于漏源双向隔离。半桥上下管不能同时导通，切换时需要合适的死区。
- **高边自举与栅源电压**：`VGS = VG − VS`。例如 `VG = 22 V`、`VS = 12 V`，则 `VGS = 10 V`。自举电路用于让高边驱动电压随源极抬高；实际适用的占空比和时序还要依据具体器件验证。

上述要点来自本日学习交接。目前只记录为理论理解，尚无本日对应的电路仿真、波形、温升或实物测量。

## 二、第三章入口：收到字节不等于得到角度

第三章前言用 JY61 的角度输出举例。截图可辨认的帧顺序为：

```text
0x55  0x53  RollL  RollH  PitchL  PitchH  YawL  YawH  VL  VH  SUM
```

UART 负责把字节送到 STM32；它本身不知道哪些字节是帧头、哪些代表角度。要从字节流得到可信的 Roll、Pitch 或 Yaw，还需依次识别帧头和数据类型、收齐一帧、校验、按高低字节组合原始值、解释有符号数，再按协议比例换算为角度。截图给出了角度原始值除以 `32768` 再乘以 `180°` 的换算关系；实际解析仍应以所用模块的完整协议为准。
