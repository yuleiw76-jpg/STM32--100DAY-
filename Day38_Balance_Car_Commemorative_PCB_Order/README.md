# Day38_Balance_Car_Commemorative_PCB_Order

## 今日成果

旅游结束返校后，重新启动 STM32 100Days 学习计划。

今天完成了两轮平衡小车纪念版 PCB 的最终确认与下单。该板不是功能电路板，而是一张接近名片尺寸的纪念卡，用来记录第一代平衡小车在 Day37 完成双环 PID 调试并成功站立的时刻。

纪念板订单已经提交，当前进入等待审核、生产和收货阶段。

## 纪念板内容

纪念板以简洁的两轮平衡小车线稿为主体，保留第一代原型车的主要结构特征，并加入以下元素：

- `STM32 > 100 DAYS`
- `FROM BREADBOARD TO BALANCE`
- `DAY 37 -- I CAN STAND UP!`
- 完成日期：`2026.08.22`
- 阻尼振荡波形，代表平衡小车从摆动到逐渐稳定的控制过程
- GitHub 项目二维码
- 金色外框与装饰线条

## 今日确认的下单规则

根据嘉立创当前免费打样规则：当月产生 PCB 或 FPC 实单消费且累计金额不低于 20 元，下个月可以继续领取免费打样券。

本次纪念板选择直接付费下单，实付金额达到 20 元，作为 8 月份的有效消费。计划在 9 月 1 日进入嘉立创下单助手的优惠券中心领取 PCB 免费打样通用券。

由于本设计使用 Altium Designer 完成，领券时应选择不限设计软件的通用券，不选择嘉立创 EDA 专用券。
