# 第五章第五节 直流无刷电机矢量控制（FOC）引子

2026-11-10 读完本节七张截图，从标题读到「答案在下一节」，完成讲解和关键口头自测。

## 力矩与力反馈

手册用机器人撑闸门的例子引入力矩控制。自行解释了机器人需要持续出力才能撑住闸门。经讲解补全了静态平衡的原因，外力矩和电机提供的反向力矩相互平衡时，关节可以几乎不动。力反馈把机器人端的受力信息传给操作者，让操作者感到阻力。

## 六步换向与开环调速

读了两相通电、一相悬空的六步换向图，以及同一相在理想化波形中经历正向通电、悬空、反向通电、再悬空的过程。独立指出潜艇例子中的 PID 控制整艘潜艇的速度，并说出机械臂需要在低速下输出较大力矩。经讲解明确，同样的开环油门指令遇到不同负载，实际电机转速可以不同。

## 转子角度、转矩与发热

自行指出定子磁场与转子磁场的相对角度会影响结果。用推门类比讲清了手册简化模型中的关系，在电流大小相同的条件下，夹角会改变能产生的电磁转矩。

口头自测中答对，在该简化模型里，两个磁场同向对齐并维持原电流时，电磁转矩为零，绕组仍有铜耗。绕组铜耗按 I²R 计算，轴端机械功率为 Tω。实际效率的判断还要结合工况和损耗。零速持载时的功率关系已讲解，尚未单独自测。
