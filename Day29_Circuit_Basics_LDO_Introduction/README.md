## 2. 电路基础

### 2.1 数字信号与模拟信号

- 数字信号使用离散状态表示信息，STM32 GPIO 通常关注逻辑高电平和逻辑低电平。
- 模拟信号的电压或电流随时间连续变化，可表示温度、声音和光强等物理量。
- STM32 可以使用 GPIO 处理数字信号，使用 ADC 等外设采集模拟信号。

### 2.2 VCC、GND 与共地

- `VCC` 表示电路的正电源节点。
- `GND` 是电路中判断其他电压时使用的参考点，不一定等于真正的大地。
- 不同模块通信时通常需要共地，使发送端和接收端拥有共同的电压参考。

这与之前的平衡小车调试直接相关：STM32、MPU6050、L298N 控制侧和逻辑分析仪都必须正确处理公共地。否则即使信号线有电压变化，接收端也可能无法正确判断高低电平。

### 2.3 常见元件外形

## 4. LDO 低压差线性稳压器

今天学习的示例芯片为 `AMS1117-3.3`，其作用是把输入的 5V 稳压为 3.3V。

基本引脚：

```text
IN  → 输入电压
OUT → 稳压输出
GND → 电压参考地
```

LDO 的特点：

- 电路结构相对简单。
- 输出电压较稳定，纹波较小。
- 适合为 STM32 等低压电路供电。
- 输入与输出压差较大或负载电流较大时，效率较低且容易发热。

近似效率：

```text
效率 ≈ Vout / Vin × 100%
```

5V 转 3.3V 时：

```text
3.3 / 5 × 100% ≈ 66%
```

LDO 的近似功耗：

```text
P损耗 ≈ (Vin - Vout) × Iout
```

假设负载电流为 200mA：

```text
(5V - 3.3V) × 0.2A = 0.34W
```

上述 0.34W 是理论计算结果，不是今天的实物测量值。
