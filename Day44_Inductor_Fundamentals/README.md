## 一、电感是什么

电感通常由导线绕成线圈。电流流过线圈时会建立磁场，并将一部分电能储存为磁场能量：

```text
E = 1/2 × L × I²
```

其中：

- `E` 是电感储存的磁场能量；
- `L` 是电感量；
- `I` 是流过电感的电流。

只要电感中存在电流，就存在与之对应的磁场。电流发生变化时，磁场也会变化，并在线圈两端产生感应电压。

## 二、电感电流为什么不能突变

电感的基本关系为：

```text
u = L × di/dt
```

若电流要在极短时间内发生很大变化，`di/dt` 就会非常大，因此需要非常高的电压。理想电感的电流不能瞬间突变，但这并不代表电流永远不变，而是电感会阻碍电流变化得过快。

与电容可以这样对比：

```text
电容：两端电压不能突变，储存电场能量
电感：通过电流不能突变，储存磁场能量
```

## 三、通电与断电时的能量变化

通电后，电感电流逐渐上升，磁场逐渐建立，电能被储存为磁场能量。

开关断开后，原来的供电通道消失，电流开始下降，磁场也随之减弱。变化的磁场会产生感应电压，其作用方向会阻碍原电流下降，因此电感会努力维持原方向的电流。此时继续供电的能量来自电感已经储存的磁场能量。

```text
通电：电流逐渐增大 → 磁场建立 → 储存能量
断电：磁场逐渐减弱 → 产生感应电压 → 维持原方向电流
```

这不是电感“为了放电或防止噪声”而主动维持电流，而是电磁感应产生的必然结果。

## 四、断电后没有回路会发生什么

如果断开供电后没有给电感留下完整的电流回路，电感仍会尝试维持原电流。为了迫使电流继续流动，电感两端可能产生很高的瞬时电压，直到寄生通路、空气击穿或器件内部通路能够让电流通过。

高压尖峰可能带来：

- 电磁噪声；
- 开关器件过压；
- 绝缘击穿；
- 元器件损坏。

因此，降低尖峰和噪声的手段不是让电感停止维持电流，而是为它提供安全、完整的续流路径。续流二极管的具体工作过程留到下一次学习。

## 五、LM2596 图中的“开关”在哪里

手册中的 LM2596 方框是简化符号，真正高速通断的功率开关管位于芯片内部：

```text
VIN（1脚）── 内部功率开关 ── OUT（2脚）── L1 ── 负载
```

内部开关导通时：

```text
+12V → VIN → 内部开关 → OUT → 电感 → 负载 → GND
```

内部开关关断时，断开的是芯片内部 `VIN → OUT` 的供电通道。`OUT` 引脚外部到电感和负载的导线仍然保持连接，只是输入电源暂时不再向该节点供电。

需要特别区分：

- `5脚 ON/OFF` 是整个芯片的使能控制，不是每个 PWM 周期高速通断的功率开关；
- `2脚 OUT` 是开关节点，并不是已经稳压完成的 `5V` 输出；
- 真正的稳压输出节点位于电感 L1 后方。

## 六、今日易错点

1. 电感不是禁止电流变化，而是阻碍电流快速变化。
2. 电流稳定时仍然存在磁场；电流变化时才会引起磁场变化和感应电压。
3. 断电后维持电流是电磁感应的结果，不是为了主动防止噪声。
4. 没有续流回路时更容易产生高压尖峰，提供安全回路才能减小风险。
5. LM2596 内部功率开关与外部 `ON/OFF` 使能引脚不是同一个概念。
