# 第五章第一节 直流有刷电机基础原理

学习日期为 2026-11-03。完成手册第一节的理论阅读和口头自测。

## 电机结构与机械换向

对照手册图二辨认了定子、转子、电刷和换向器。在图示的永磁有刷电机模型中，定子提供磁场，固定电刷通过旋转的换向片给转子线圈供电。线圈越过零转矩位置时，电刷接触的换向片互换，线圈电流反向。同一根导线移到转轴另一侧后，受力也反向，因此绕轴转矩仍沿原方向。

自测时自行解释了换向片与固定电刷的接触切换，经提示纠正了部件名称，经追问补全了转矩同向的原因。

## 电机参数与减速增矩

阅读了额定电压、空载电流、空载转速和堵转电流。独立判断出同一马达在相同输入转速和转矩下，使用 1:120 减速箱比 1:48 输出更慢、转矩更大。经讲解，明确了在忽略传动损耗时，机械功率由转矩与角速度的乘积给出，1:120 的输出转速是 1:48 的 0.4 倍，输出转矩是 2.5 倍。

## 电流闭环

在永磁有刷电机的近似模型中，电流决定电磁转矩。独立答出目标电流保持原值时，电机转矩基本不变，小车上坡会因原有驱动力不足以维持原速而减速。能区分电流环调节的电流和速度环调节的转速。
