## 一、推挽输出

STM32的推挽输出级可以简化为一只上方 `P-MOS` 和一只下方 `N-MOS`：

```text
VDD
 │
P-MOS
 │
GPIO引脚
 │
N-MOS
 │
GND
```

### 输出高电平

```text
P-MOS导通，N-MOS关断
VDD → P-MOS → GPIO引脚
```

引脚被主动拉向VDD，可以向外部负载提供电流。

### 输出低电平

```text
P-MOS关断，N-MOS导通
GPIO引脚 → N-MOS → GND
```

引脚被主动拉向GND，可以吸收外部电流。

因此推挽输出能够主动输出高、低电平，通常不需要额外上拉电阻，是最常用的普通GPIO输出方式。

手册中的S8050、S8550电路用于辅助理解推挽概念；STM32内部实际使用的是CMOS输出级。

## 二、开漏输出

开漏输出只使用下方的 `N-MOS`，没有主动连接到VDD的上管。

```text
写0：N-MOS导通，GPIO被主动拉低
写1：N-MOS关断，GPIO进入高阻态
```

开漏“写1”不是主动输出3.3V，而是释放引脚。要获得稳定高电平，需要通过上拉电阻连接到允许的电源电压：

```text
3.3V
 │
上拉电阻
 │
总线 ── 多个开漏器件
```

当所有器件都释放线路时，上拉电阻将总线拉高；只要任意器件导通N-MOS，总线就被拉低。

## 三、为什么I2C使用开漏

I2C允许多个器件共用 `SDA` 和 `SCL`。开漏结构让每个器件只能执行两种动作：

```text
拉低总线
释放总线
```

如果改用推挽输出，一个器件主动输出高电平、另一个器件主动输出低电平时，可能形成：

```text
VDD → 上管 → 总线 → 下管 → GND
```

这会造成输出冲突和较大电流。使用开漏后，没有器件会主动把线路推高，因此能够安全共享总线。

## 四、普通输出与复用输出

“复用”不会改变推挽或开漏的电气结构，只改变输出控制信号来自哪里：

- 普通输出：由GPIO输出寄存器和程序控制；
- 复用输出：由UART、SPI、定时器、I2C等片上外设控制。

| 功能 | 应选模式 | 原因 |
| --- | --- | --- |
| 程序控制LED | 普通推挽输出 | 程序主动控制高低电平 |
| UART TX | 复用推挽输出 | UART外设控制发送波形 |
| 定时器PWM | 复用推挽输出 | 定时器外设控制PWM波形 |
| 硬件I2C SDA/SCL | 复用开漏输出 | I2C外设控制共享开漏总线 |

## 五、GPIO内部信号路径

### 输出路径

```text
GPIO输出寄存器或片上外设
  → 输出控制电路
  → P-MOS/N-MOS输出级
  → IO引脚
```

### 输入路径

```text
IO引脚
  → 输入保护与上下拉结构
  → 施密特触发器
  → 输入数据寄存器或片上外设
```

## 六、施密特触发器

施密特触发器使用高、低两个不同门限，将变化缓慢或带有噪声的输入电压转换成稳定的数字电平。

按照手册中的示意门限：

```text
输入上升：超过2.5V后，输出才从0变成1
输入下降：低于1.5V后，输出才从1变成0
处于1.5V～2.5V之间：保持之前的状态
```

因此，输入电压在两个门限之间小幅波动时，数字结果不会反复翻转。`2.5V`和`1.5V`只是手册中的原理示例，具体芯片的实际门限应以数据手册为准。

## 七、钳位保护结构

手册中直接说明：GPIO引脚附近的两个保护结构属于钳位保护电路，`VDD`为电源端，`VSS`为地端，用于应对高于电源或低于地电位的异常电压。

### 补充知识（非本节手册验收内容）

钳位结构不能当作正常工作的稳压器或电平转换器。外部电压是否允许接入，仍需要根据具体引脚和芯片数据手册判断。本项只作为安全提醒，不计入今天的手册验收。

## 八、四种输出模式对比

| 模式 | 控制来源 | 主动拉高 | 主动拉低 | 获得高电平是否需要上拉 |
| --- | --- | --- | --- | --- |
| 推挽输出 | GPIO程序 | 是 | 是 | 否 |
| 复用推挽输出 | 片上外设 | 是 | 是 | 否 |
| 开漏输出 | GPIO程序 | 否 | 是 | 是 |
| 复用开漏输出 | 片上外设 | 否 | 是 | 是 |

## 安全提醒

- LED需要串联限流电阻；
- GPIO不能直接驱动电机等大电流或感性负载；
- 开漏输出的上拉电压必须符合具体引脚的数据手册要求。
