## 一、为什么需要负压

上一节学习CD4051时，`VEE` 是模拟信号允许范围的下边界。若要让CD4051传递低于GND的模拟信号，就可能需要一条负电源轨。SGM3204电荷泵可以从正电源产生负压，为这类电路提供一种方案。

负压始终是**相对于同一个GND参考点**而言。例如万用表黑表笔接GND、红表笔接负压输出，理想情况下会显示约 `−3.3V`。

## 二、四开关示意图中的两个阶段

手册中的 `S1～S4` 是说明工作原理的理想开关，不是要求在SGM3204外部再接四只开关。

**阶段1：给飞跨电容充电。** `S1、S4` 闭合，另外两只开关断开。若输入为 `+5V`，飞跨电容左端为 `+5V`，右端为 `0V`，两端电压差为 `5V`。

**阶段2：翻转节点电位。** 断开 `S1、S4`，闭合 `S2、S3`。飞跨电容左端被接到 `0V`。在理想情况下，电容两端电压不会瞬间改变，因此右端变为 `−5V`，并向输出端转移电荷。

```text
输入 +5V   → 理想负压约 −5V
输入 +3.3V → 理想负压约 −3.3V
```

这两个数值来自**理想模型**，不是任何负载条件下都保证达到的实测值。

## 三、SGM3204应用电路中的电容

| 元件 | 截图标注 | 作用 |
| --- | --- | --- |
| `C27` | 10µF | 飞跨电容，连接 `CFLY+` 与 `CFLY−`，随内部开关切换搬运电荷 |
| `C28、C29` | 100nF、10µF | 输入侧去耦与储能 |
| `C30、C31` | 100nF、10µF | 输出侧储能与降低纹波 |

截图电路中，`IN` 接正电源，`GND` 接系统地，`OUT` 是负压输出，`EN` 用于控制芯片运行。连接和元件取值应以实际使用的芯片数据手册、器件额定值和PCB设计为准。

## 四、为什么实际输出不是恒定的−3.3V

SGM3204属于**非稳压电荷泵**。输入为 `+3.3V` 时，空载输出可以接近 `−3.3V`；连接负载后，开关、电容等非理想因素会造成压降，输出通常不再精确等于 `−3.3V`，还可能出现纹波。

负载越重，输出电容被抽走的电荷越多。如果补充电荷的速度不足，负压的绝对值就会减小，输出朝 `0V` 方向变化。

资料中的“最大输出电流200mA”**不等于**“输出200mA时仍能精确维持−3.3V”。设计时要核对对应输入电压、负载和温度条件，并通过实测确认目标电路能否正常工作。

## 五、停机后输出会怎样

若 `EN` 使芯片停止切换，飞跨电容不再持续向输出补充电荷。输出电容能让负压短时间保持，但只要负载仍在耗电，就不能永久维持 `−3.3V`；输出会逐渐向 `0V` 变化。实际变化速度取决于输出电容和外部负载。

## 六、与CD4051的联系

可考虑将负压输出用于CD4051的 `VEE`，使模拟开关能够传递负电压信号。但连接之前必须核对：

- CD4051具体型号的数据手册及 `VDD、VSS、VEE` 允许范围；
- 目标信号的最高和最低电压；
- 负压电源在实际负载下的输出幅值和纹波；
- 两个电路是否采用正确的共同参考地。

不能仅凭“SGM3204能产生负压”就认定整个模拟信号链已经安全、准确。

## 八、待验证与安全事项

本次只完成原理学习，尚未测量实际电路。后续若做实物实验：

1. 断电检查芯片方向、引脚、输入电压和电容连接；
2. 使用设有限流的低压电源，先不连接目标负载；
3. 万用表黑表笔接GND、红表笔接OUT，确认输出极性；
4. 再逐步增加合适负载，记录输入电压、负载电流和输出电压；有示波器时观察纹波；
5. 在测得的负压满足CD4051及模拟信号要求后，才考虑连接后级电路。

不要把负压输出误接到只能承受 `0～3.3V` 的STM32引脚，也不要把手册中的“已验证”当作自己电路的测量结果。
