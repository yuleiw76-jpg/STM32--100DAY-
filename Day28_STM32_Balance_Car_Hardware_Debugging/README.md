今日总结｜平衡小车供电与PID调试
今天首先更换了新的J-Link和STM32开发板，并通过跑马灯程序确认下载、烧录和STM32运行都正常。
重新下载平衡小车程序后，出现了L298N亮、STM32的PC13规律闪烁、MPU模块不亮的问题。通过最小系统测试，只连接MPU的3.3V和GND时模块能够正常发光；重新连接PA4、PA5并复位后，PC13停止闪烁，说明MPU通信和DMP初始化已经成功。最终判断问题主要来自面包板或杜邦线接触不良。
在直立环调试中，进一步理解了PID参数和实际电机输出的关系。当前代码输出被限制在-2000～+2000，TIM4周期为2999，因此最大PWM约为67%。当P=1200时，只要角度误差超过约1.67°就会达到输出限幅。PID数值达到四位数，并不代表电机还会继续加速；继续提高P只会让平衡点附近更加敏感。
随后小车摔倒，所有模块突然断电。重新连接后电机只能短暂、缓慢转动，随后再次全部熄灭。电池单独连接L298N时，L298N也不亮，因此当前更可能是电池电量不足，或者电机堵转导致电池保护板触发欠压、过流保护。已经购买对应充电器，下一步先将电池安全充满，再分阶段检查电源系统。
今日主要收获：
初始化失败不一定是代码问题，首先要检查供电和接触。
MPU接线恢复后，需要按Reset重新执行初始化。
PID参数再大，也会受到软件限幅和电源能力限制。
电机无力、系统突然全部断电，可能是电池掉压或保护板动作。
供电系统不稳定时，所有PID调参结果都没有参考意义。
调试顺序应该是：电源稳定 → MPU数据正常 → 电机方向正确 → PWM正常 → 最后再调P和D。
当前状态是STM32、J-Link、MPU和DMP基本确认正常，主要待确认的是电池电量、放电能力以及整车供电连接。充满电后应先让轮子悬空测试，确认系统不会再次断电，再继续直立环PD调参。
