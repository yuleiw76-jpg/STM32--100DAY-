# Day88｜FOC驱动器电路设计

学习日期：2026-11-17。手册位置：第五章第八节《FOC驱动器电路设计》。

本节按“读图理解电路、测角与安装关系”的范围收尾。9张截图已读完，四项关键口头自测独立答对。原理图设计、独立编程和实物验证尚无本次结果。

## 学到的整板关系

```text
STM32读取AS5600角度
  → 结合极对数、方向与零位得到控制所需角度
  → 计算SVPWM三相占空比并写CCR
  → PWM控制DRV8313内部三个半桥
  → 电源经功率桥向电机供电
  → 轴带着磁铁旋转，AS5600继续检测角度
```

供电通路、PWM控制信号和I2C角度数据分别承担不同任务。

## 本次主要内容

- 分立六MOS功率桥与EG3014栅极驱动的连接；MOS开关的充放电与VGS参考。
- 栅极电阻和并联二极管影响开通/关断速度；自举电容给高侧驱动提供储能。
- DRV8313集成三个半桥和驱动，EN拉高后由三路PWM控制IN1/2/3，OUT1/2/3接电机。
- 正常使能时IN高为上管导通，IN低为下管导通；EN低才使该桥臂两管关闭。
- VM、电荷泵相关引脚、复位休眠与故障指示；Thermal pad焊接接地和散热。
- 整板稳压供电、CAN收发接口、AS5600单圈测角与增量式A/B编码器的区别。
- 磁铁随轴、传感器固定；直径方向两极磁化、居中、气隙和定位件的作用。
- PCB固定孔、器件布局、走线、散热、M3结构例子、No Net和Plated的区别。

## 教材与工程的边界

用户提供的整合包中，当前main调用FOC_SVPWM(2,0,angle_now)，属于根据角度反馈施加固定Uq/Ud电压指令的示例。当前已读控制链没有相电流反馈和电流PI，不能当作精确电流/转矩闭环已实现。

静态核对保留三处后续关注：DRV8313的V3P3旁路连接、源码向下计数与前节中心对齐图的配置差别，以及软件I2C的SDA模式宏与读写引脚不一致。详见完整交接。它们尚未修改或用实物验证，不妨碍本次读图理解范围收尾。
