## 从测角到三路 PWM

```text
TIM1 准备三路 PWM，软件 I²C 准备读 AS5600
  → 启动时对齐转子，记录电角度零位 angle_ori
  → 循环读角并减去零位，得到 angle_now
  → FOC_SVPWM(2, 0, angle_now) 计算三路占空比
  → 写入 TIM1 的 CCR1、CCR2、CCR3，驱动 DRV8313 的三个桥臂
```

- **安装。** 2804 电机的中空轴用支架定位磁铁。磁铁随转子转动，驱动板上的 AS5600 固定并与磁铁对准。
- **读角。** `getAngle()` 每机械圈读到 0～4095 格。程序按相邻读数之差处理跨零，将累计机械角乘例程设定的 7 极对，返回累计电角度。阈值判断依赖相邻两次读数之间的实际转动足够小。
- **输出。** 例程使用角度反馈和固定的 dq 电压指令，当前有效调用为 `Uq=2`、`Ud=0`。SVPWM 将目标电压矢量换算为三路占空比。实际相电流、力矩和试转效果待测。

## 本人修改的两条 SDA 宏

工程的 `HARDWARE/ENCODER/encoder.c` 用 PA6 作 SCL、PA7 作 SDA。原 `SDA_IN()`、`SDA_OUT()` 用 `0xFF0FFFFF` 和 `<< 20`，写的是 PA5 的 `CRL[23:20]`。SDA 的引脚电平读写用的是 PA7，所以本人按指导将模式切换也改到 PA7 的 `CRL[31:28]`。以下是从保存源码核对的实际改动：

```c
#define SDA_IN()  { GPIOA->CRL &= 0x0FFFFFFFU; GPIOA->CRL |= (8U << 28); }
#define SDA_OUT() { GPIOA->CRL &= 0x0FFFFFFFU; GPIOA->CRL |= (3U << 28); }
```

`0x0FFFFFFF` 保留低 28 位并清除 PA7 的四位配置字段，`<< 28` 将输入或输出模式写入该字段。当前确认的是源码中的位段与引脚一致，实际 I²C 通信和读角待验证。

## PWM 频率的静态核对

`FOC_init()` 调用 `TIM1_Init(4096 - 1, 0)`。取 TIM1 时钟 72 MHz、PSC = 0、ARR = 4095，计算如下。

| 配置 | 每个 PWM 周期的计数拍数 | 静态计算 |
| --- | ---: | ---: |
| 手册中心对齐 `CenterAligned1` | `2 × 4095` | 约 113.75 µs，8.79 kHz |
| 本地源码向下计数 `Down` | `4095 + 1` | 约 56.89 µs，17.58 kHz |

本地 `FOC.c` 的 114 µs 注释与 `tim1.c` 的向下计数配置有出入。实际输出以之后的板上测量为准。

## 学习验收

- 独立判断原始读数从 10 跳到 4090 时，例程按阈值规则减去一整圈机械角。经讲解后复述了「采样间隔足够短」这一假设。
- 独立判断 `Ud=0` 时，正、负 `Uq` 让电压矢量相对当前转子电角度分别偏移 +90°、−90°。具体绝对角度在讲解中补算。
- 复习了 SVPWM 中有效矢量作用时间如何合成三路占空比。
