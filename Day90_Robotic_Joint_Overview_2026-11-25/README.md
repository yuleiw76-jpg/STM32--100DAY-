## 学习范围

| 范围 | 讲清的关系 |
| --- | --- |
| 之前小 FOC 电机单元的不足 | 2804 裸电机的可用转矩小。第九节例程用角度决定电压矢量方向并给固定 `Uq`，缺少相电流闭环所需的反馈。实际转矩和转速受负载等条件影响。 |
| 完整关节框架 | 从样机照片、手绘草图和框架图识别电机、行星减速器、FOC 控制器、第一编码器和第二编码器。行星减速器降低输出转速并提高可用转矩。实际增矩受效率影响，工作电流受整板散热、走线和工况约束。 |
| 第一编码器与控制板 | 第一编码器在电机侧读取转子机械角，程序结合方向、极对数与零位得到电角度。AS5047P 可用 A/B 增量信号计数，也可通过 SPI 读取单圈绝对角度。样机将第一编码器和控制器分成两块板，控制器以六颗分立 MOS 管组成三个半桥。手册的整板电流是作者所述样机范围。 |
| 双编码器与三路电流反馈 | 教材的 8:1 减速例中，电机转 360°，输出轴转 45°。第一编码器的单圈读数会重复，第二编码器直接读减速后的输出轴实际角度。控制板图中的三路采样电阻用于获取 A/B/C 相电流，采样电压差与电流满足 `I = ΔV/R`。采样支路与 ADC 时机留到原理图确认。 |
| 工程编译与首次上电准备 | 预处理时 `FOC_utils.h` 的 `_sqrt` 宏把调用名映射到 `_sqrtApprox`。如果宏在处理工具链 `math.h` 时已生效，系统的 double 版本声明也被替换，同名后与工程 float 版本签名冲突。手册作者注释系统头文件中的冲突项，工程内更名是课堂讨论的替代做法。首次上电还要核对适用供电、用 `foc_rotor_align()` 建立电角度零位，并核对 `PMSM_param_init()` 的实物参数。 |

## 实际作答与纠正

| 检查点 | 本人回答与学习证据 |
| --- | --- |
| 小 FOC 单元的两项限制 | 本人独立答出「扭矩太小与控制不够精确」。随后补讲第九节示例缺少测相电流及调节电流的链路。 |
| 动力路径和第一编码器 | 本人独立认出电机经行星减速器减速增矩，第一编码器在转子侧，AS5047P 支持增量方式。助手补清磁铁随转子、传感器固定，以及机械角换算电角。 |
| 第二编码器与采样电阻 | 本人独立指出第二编码器补上输出轴的实际角度，采样电阻补上电流反馈。助手将「流经 MOS 管的电流」补清为该板用于获取相电流的反馈，实际采样支路待看原理图。 |
| 为什么还要对齐零位 | 首答为「不做对齐就不知道转了多少角度」。相邻读数可以求步进变化量，FOC 还需要已知的电角度零位。讲解例中，对齐读数 30°、上次 40°、本次 55°，本次比上次变 15°，本次相对对齐位置为 25°。本人追问「相对零位机械角也就是角度变化值吧」，经解释澄清两个差值的参考点。完整独立说明待另行观察。 |

补充区分了电机转子的电角度零位与减速器输出轴的机械零位。输出轴的姿态参考用于关节位置控制，电角参考用于确定电压矢量方向。未对本节概念理解推断独立工程实现能力。
