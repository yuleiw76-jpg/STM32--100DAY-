## 本例接线与参数

| 连接 | 用途 |
| --- | --- |
| PA6 → PA0 | TIM3_CH1输出PWM，送入TIM2_CH1捕获 |
| PA9 → USB转TTL的RX | USART1打印频率 |
| STM32 GND → USB转TTL GND | 共地 |

串口设置为9600、8位数据、1位停止、无校验。STM32沿用原供电与下载接法；USB转TTL的TX、VCC不需要连接。接线先断电，避免PA0、PA6同时接其他驱动源，不把5V接到GPIO。

按本例设计的72MHz定时器时钟，PSC=71得到1MHz计数频率；TIM3的ARR=19999、CCR1=10000，产生标称50Hz、50%占空比PWM。TIM2的ARR=65535，一轮65536个计数。手册“PA0是TIM3_CH1”的文字为笔误，本例PA0是TIM2_CH1。

50.02Hz与标称50Hz相差0.02Hz，但这不是对独立标准源测出的绝对误差。两个定时器共用板上时钟；本次确认正常捕获、换算与串口显示链路跑通，不对差值来源作未经验证的归因。
