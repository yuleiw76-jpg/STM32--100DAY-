## 一、本征半导体与载流子

硅原子通过价电子与周围原子形成共价键。受到热运动影响时，部分共价键中的电子可能获得足够能量并脱离，从而同时产生：

- 一个可以参与导电的自由电子；
- 一个缺少电子的位置，即空穴。

自由电子和空穴都能在电场作用下参与导电，因此统称为载流子。

没有外加电场时，载流子虽然一直进行无规则热运动，但各个方向的运动在宏观上相互抵消，因此净电流为 0。自由电子重新填入空穴时，两者发生复合，共价键重新恢复完整。

## 二、N 型与 P 型半导体

### N 型半导体

向硅中掺入五价的磷原子后，磷的四个价电子参与共价键，多出的一个电子容易成为自由电子。磷失去电子后成为固定在晶格中的磷正离子。

- 自由电子是多数载流子；
- 空穴是少数载流子；
- 固定的磷正离子不属于载流子；
- 自由电子与磷正离子的电荷相互平衡，因此材料整体仍然呈电中性。

N 型中的少量空穴主要来自热运动产生的电子—空穴对。

### P 型半导体

向硅中掺入三价的硼原子后，形成第四个完整共价键时缺少一个电子。硼从附近共价键接受电子后成为固定的硼负离子，而电子原来的位置留下空穴。

- 空穴是多数载流子；
- 自由电子是少数载流子；
- 固定的硼负离子不属于载流子；
- 空穴与硼负离子的电荷相互平衡，因此材料整体仍然呈电中性。

电子不断填补相邻空穴时，并不会额外产生自由电子，而是让空穴的位置发生移动。

## 三、PN 结与耗尽层

P 型与 N 型半导体接触后，由于载流子浓度不同：

- N 区自由电子向 P 区扩散；
- P 区空穴向 N 区扩散；
- 电子与空穴在交界处复合。

复合后，PN 结附近的可移动载流子减少，但固定的杂质离子仍然存在：

```text
P 区耗尽层                    N 区耗尽层
固定硼负离子                 固定磷正离子
− − − − −         |         + + + + +
```

这片缺少可移动载流子的区域称为耗尽层或空间电荷区。“耗尽”表示自由电子和空穴大量减少，并不代表该区域完全没有电荷。

## 四、内建电场与动态平衡

耗尽层中固定的正、负离子会形成由 N 区指向 P 区的内建电场：

```text
P 区（负）  ←←←  内建电场  ←←←  N 区（正）
```

- 电子带负电，受力方向与电场相反，因此被推回 N 区；
- 空穴等效带正电，受力方向与电场相同，因此被推回 P 区。

载流子的扩散作用与内建电场产生的漂移作用最终达到动态平衡。此时载流子并非停止运动，而是两个方向的电流相互抵消，宏观净电流为 0。

## 五、正向与反向偏置

### 正向偏置

电源正极接 P 区、负极接 N 区时，外加电场方向为 P 区到 N 区，与内建电场相反。

外加电场削弱内建电场，使耗尽层变窄、势垒降低，更多电子和空穴能够穿过 PN 结并形成持续电流。

### 反向偏置

电源负极接 P 区、正极接 N 区时，外加电场与内建电场方向相同。

多数载流子被进一步拉离交界处，使耗尽层变宽、势垒升高，因此普通二极管反向时只有很小的漏电流。

## 六、二极管的正向伏安特性

硅二极管并不是在 0.70V 时突然由截止变为导通。随着正向电压升高，势垒逐渐降低，正向电流会连续地、非线性地快速增大。

工程中常说的“硅二极管导通压降约为 0.7V”只是常用工作电流下的近似值，实际压降还会受到电流、温度和器件型号影响。
