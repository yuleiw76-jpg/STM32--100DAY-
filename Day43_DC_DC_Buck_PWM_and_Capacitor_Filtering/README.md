## 一、LDO 的损耗与效率

LDO 通过消耗输入、输出之间的压差来稳压。忽略静态电流时，可以近似认为输入电流等于输出电流：

```text
Pout  = Vout × Iout
Ploss = (Vin - Vout) × Iout
η     ≈ Vout / Vin
```

以 `12V → 5V、负载电流 0.5A` 为例：

```text
输出功率 Pout = 5V × 0.5A = 2.5W
输入功率 Pin  = 12V × 0.5A = 6W
发热功率 Ploss = 6W - 2.5W = 3.5W
效率 η = 2.5W / 6W ≈ 41.7%
```

其中 `41.7%` 是效率，不是功率。输出功率为 `2.5W`，理想化计算下需要转化为热量的功率为 `3.5W`。即使忽略其他损耗，线性稳压器的理想效率也不会因此变成 100%。

## 二、PWM 与平均输出电压

Buck 型 DC-DC 芯片内部的开关并不能直接产生任意中间电压，而是在输入电压和接近 `0V` 之间高速切换。PWM 通过改变一个周期内高电平所占的比例来改变理想平均电压：

```text
D = Ton / T
Uavg ≈ D × Vin
```

若要把 `12V` 的输入调成理想平均值 `5V`：

```text
D = 5V / 12V ≈ 41.7%
```

当 PWM 频率为 `100kHz` 时：

```text
周期 T    = 1 / 100kHz = 10μs
导通时间 Ton  = 10μs × 41.7% = 4.17μs
关断时间 Toff = 10μs - 4.17μs = 5.83μs
```

平均值符合要求，不代表原始 PWM 可以直接给 STM32 供电。未经滤波和稳压的波形仍会在 `0V` 与 `12V` 之间跳变，其瞬时峰值远超 MCU 电源允许范围。

## 三、反馈调节

LM2596 的反馈端会采样实际输出电压，并与芯片内部的参考值比较。芯片根据偏差调整后续开关动作，使输出在输入电压或负载发生变化时仍能回到目标值附近。

可以把这个过程概括为：

```text
测量输出 → 与目标比较 → 调整开关占空比 → 再次测量
```

反馈端是用于测量的信号入口，不是向负载提供大电流的功率输出端。

## 四、滤波电容为什么能减小电压波动

理想电容满足：

```text
i = C × du/dt
```

因此电容两端的电压不能瞬间突变。把电容并联在输出端后：

- 前级提供的电流大于负载所需电流时，多出的电流给电容充电；
- 前级提供的电流小于负载所需电流时，电容向负载放电；
- 电容不断充电和放电，减缓输出电压的上升与下降，从而减小纹波。

在一小段时间内，可以用下面的近似式估算电压变化：

```text
ΔU ≈ I × Δt / C
```

若电容需要提供 `0.2A`，持续 `10μs`：

```text
C = 220μF：ΔU ≈ 9.09mV
C = 110μF：ΔU ≈ 18.18mV
```

在电流和持续时间相同的情况下，电容量减半，电压变化量会加倍。增大电容能够减缓电压变化，但真实电路还会受到电容参数、负载变化和控制过程等因素影响，不能只靠无限增大电容量解决所有问题。

## 五、今日易错点

1. `41.7%` 是效率或占空比时，必须结合上下文判断，不能称为“工作功率”。
2. PWM 的平均电压是时间平均值，不表示每个瞬间都等于该电压。
3. 电容量减半时，在其他条件不变的情况下，`ΔU` 加倍，而不是乘以 `1.5`。
4. 电容只能减缓电压变化，完整 Buck 稳压还需要后续尚未学习的器件和闭环控制。
