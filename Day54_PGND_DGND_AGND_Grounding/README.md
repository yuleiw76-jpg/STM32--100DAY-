## 一、地的本质

地既是电路测量电压时的参考点，也是电流返回电源的路径。电流不会到达 GND 后消失，而是通过回流路径回到电源。

铜皮和走线都存在微小的电阻与电感，变化电流会在回流路径上产生电压：

```text
V噪声 ≈ I × R + L × di/dt
```

因此，同一块 PCB 上不同位置的“0V”在瞬间可能并不完全相等。大电流或快速变化的电流尤其容易抬高局部地电位，这种现象常被称为地弹噪声。

## 二、PGND、DGND、AGND

| 地网 | 主要服务的电路 | 布局重点 |
| --- | --- | --- |
| `PGND` 功率地 | 电机、MOS 管、开关电源等大电流回路 | 回路短而粗、面积小，避免经过敏感区域 |
| `DGND` 数字地 | STM32、UART、I2C、数字逻辑 | 为数字信号提供连续、就近的回流路径 |
| `AGND` 模拟地 | ADC、运放、模拟传感器和采样电路 | 保持安静，远离功率开关和高速边沿 |

三种地通常最终仍需要建立共同参考，但应控制它们的连接位置和回流路径，避免功率电流与微弱模拟信号共用一段高阻抗路径。

### ACS712 的细节

ACS712 的 `IP+`、`IP-` 承担被测大电流；`VCC`、`GND`、`VIOUT`、`FILTER` 属于低压模拟测量侧。在今天截图所示的应用中，低压测量侧的 GND 应归入 `AGND` 区域，而大电流路径不能穿过敏感模拟回路。

## 三、共用阻抗与 ADC 跳动

如果电机大电流和 ADC 共用一段细长地线，电机启动时的大电流以及较大的 `di/dt` 会在这段公共阻抗上产生瞬时压降。

此时 ADC 所使用的“0V”参考会发生变化，即使传感器输出没有真正变化，ADC 结果也可能跳动。问题的核心不只是“电机噪声大”，而是：

```text
功率回流路径经过了敏感模拟电路的参考路径
```

## 四、0Ω 电阻与单点连接

0Ω 电阻连接两个地网时，焊接后在电气上接近一根导线。它的主要作用是：

- 指定两个地网的受控连接位置；
- 让原理图和 PCB 可以分别管理地网；
- 方便测量、断开、调试和后续改版；
- 为不同区域建立共同参考。

0Ω 电阻 **不能当作滤波器**，也不是依靠“狭窄通道”阻挡噪声。通道过窄反而会增加阻抗，使大电流产生更严重的压降和地弹。

单点接地也不是所有电路的固定答案。它能减少干扰的前提，是正确规划各区域的回流路径、避免共用阻抗；具体连接方法还应结合芯片数据手册、参考设计、频率和 PCB 层叠判断。

## 五、连续地平面与功能分区

在很多混合信号 PCB 中，以下方案通常更安全：

```text
保持连续地平面
  → 模拟、数字、功率器件按功能分区放置
  → 让各自回流在本区域内就近闭合
  → 不让敏感信号进入功率区域
```

把地平面机械地切成几块，却让 ADC、PWM、时钟等信号跨越切缝，会破坏信号下方的连续回流路径。回流电流只能绕远路，导致环路面积增大，更容易接收和辐射干扰。

因此，网络名称相同或不同都不能代替正确的物理布局。真正需要检查的是电流从哪里流回、是否绕行，以及是否经过其他电路的敏感参考区域。

## 六、边沿速度同样重要

数字信号是否容易产生高频干扰，不能只看重复频率，还要看上升沿和下降沿。

例如一个只有 `10kHz` 的 PWM，如果边沿非常陡，仍然包含较强的高频成分。它不应随意穿过 ADC 模拟区域，也不应跨越地平面切缝。

## 七、电机启动导致 ADC 乱跳的排查顺序

```text
确认电机、MOS 管和电源的 PGND 大电流回路
  → 检查它是否与 ADC/AGND 共用细长走线或狭窄铜皮
  → 检查 ADC 信号线是否进入 PGND 区域或跨越地缝
  → 检查 AGND、DGND、PGND 的实际连接位置
  → 检查 ADC 与传感器是否具有就近、连续的参考和回流路径
  → 条件允许时用示波器比较电机启动前后的地电位与 ADC 输入
```
