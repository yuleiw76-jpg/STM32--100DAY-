## 学到的基础概念

| 内容 | 今天的学习与讨论记录 |
| --- | --- |
| UART与RS485 | 在本节透明转换的使用场景中，UART收发的字节内容保持不变，RS485模块改变的是线路电信号形式 |
| 差分判断 | 接收端根据A、B两线的电压差判断数据，而非只看某根线相对本地地的电压 |
| 抗相近干扰 | 若干扰在两线上叠加得相近，两线压差变化较小，有助于稳定通信；不能推成不受任何干扰 |
| 地电位差 | 差分接收仍受芯片允许输入范围约束；实际接地需结合模块及隔离设计，不能只凭“差分”决定 |
| 两线半双工 | 本节使用一对线分时收发；不是所有RS485系统都只有这一种方式 |
| 自动方向控制 | 模块自动切换收发方向，不等于允许多个设备同时发送 |
| 距离与速度 | 通信能力受速率、线材、连接及干扰条件影响；不能承诺任意条件下1000米无失真、无丢包 |
| TX/RX接线 | 依据实际输入、输出定义核对，不能把“TX接TX”或“TX接RX”当成所有模块通用规则 |

## 今天纠正的认识

**最初理解：**差分通信不需要共地。

**讨论后明确：**“按两线压差判断”不等于可以忽略地电位差。芯片能容许的输入共模范围有限；信号参考、保护/机壳接地、屏蔽层以及是否隔离，需要分开判断。

本次不提供某个未知模块的具体接地方案，也不把结论反过来简化成“所有场合都把两端GND直接相连”。[TI RS-485设计指南第11节](https://www.ti.com/lit/an/slla272d/slla272d.pdf)用于整理时核对这一限制；不表示本人已阅读或验证完整接地设计。
