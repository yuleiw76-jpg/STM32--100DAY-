## 从开关状态到三路 PWM

交接报告已复习三个桥臂与八种开关状态，明确 U4(100)、U6(110) 是同一三相逆变桥的整体状态。两个有效电压矢量的时间组合仍然同时涉及 A/B/C 三个桥臂。

第一扇区采用对称顺序：

```text
000 → 100 → 110 → 111 → 110 → 100 → 000
```

相邻状态每次只改变一个桥臂。交接比较了 100→000 只改变 A、100→111 改变 B/C，在其他条件相近时前者通常有较少的开关损耗。

代码 T1、T2、T0 是归一化的作用时间比例，满足 T1+T2+T0=1。T1 对应扇区起始方向，T2 对应扇区结束方向，T0 是两个零状态合计比例。教材波形图另用 T0/T7 分别命名 000/111 的时间，阅读时需对齐记号。

## 关键卡点与中心对齐算例

用户的疑惑是：既然目标是安排各整体状态的作用时间，为什么代码计算三个桥臂分别为 1 的时间？换成占空比后，是否仍保证原来的状态停留时间？

报告通过同周期、同中心、对应 PWM 模式及极性下的居中高电平波形解释这一关系。理想互补开关算例为：

\[
T_1=0.3,\qquad T_2=0.4,\qquad T_0=0.3
\]

\[
T_a=T_1+T_2+T_0/2=0.85,\quad
T_b=T_2+T_0/2=0.55,\quad
T_c=T_0/2=0.15
\]

三路高脉冲居中时，可以反算整周期内的状态占比：

| 状态 | 总时间占比 | 结果 |
| --- | --- | --- |
| 100 | Ta−Tb | 0.30 |
| 110 | Tb−Tc | 0.40 |
| 111 | Tc | 0.15 |
| 000 | 1−Ta | 0.15 |

因此三路 duty 是同一组状态作用时间的可执行表示。这里分析的是本例选用的中心对齐方案，实际开关边沿还需结合定时器与驱动配置。

报告保留的用户总结原话为：“我们是采用中心对齐，只要算出来ABC各自高电平持续时间，就自动对齐控制各个桥开关了。”这是经过画图、例子和反复讨论后的复述证据，不能等同于已独立实现或实测。

## FOC_SVPWM 函数的完整逻辑

报告称已完整阅读函数 `FOC_SVPWM(float Uq, float Ud, float angle)`，包括六个扇区及写入比较值的最后三行。

| 步骤 | 已讨论的计算与含义 |
| --- | --- |
| 幅值 | sqrt(Ud²+Uq²)/VOLTAGE_LIMIT，按例程将电压幅值相对母线归一化。它不是直接给某个桥臂的 duty。Ud=0 时分子为 abs(Uq) |
| 方向 | 输入 angle 为转子电角度；加 atan2(Uq,Ud) 后，同名变量保存目标电压相对固定 α 轴的方向。单位为弧度，归一化范围为 [0,2π) |
| 扇区 | floor(angle/(π/3))+1 得到 1～6 |
| 有效时间 | T1 用目标方向与扇区结束边界的夹角，求起始矢量比例；T2 用与起始边界的夹角，求结束矢量比例 |
| 零时间 | T0=1−T1−T2；交接已提醒真实实现需处理限幅，避免出现负的零时间 |
| 三路 duty | switch 按六种扇区映射，将各状态里 A/B/C 位为 1 的时间累加，得到 Ta/Tb/Tc |
| 定时器执行 | 三路 duty 乘与 ARR 配置有关的 _PWM_RANGE，再由 TIM_SetCompare1/2/3 写 TIM1 的 CCR1/2/3 |

第二扇区中，T1 对应 60° 起始矢量，T2 对应 120° 结束矢量。报告记载用户曾对 T1 公式里出现 120° 提出疑问，并自行画图后理解了几何对应关系。后续使用“扇区起始方向/结束方向”，避免“前边/后边”的歧义。

Ud=0、Uq 正负时，电压相对 d 轴角度分别为正负 90°；新 angle 是要施加的电压方向，不能直接当作转子下一个位置或实际电流方向。输入电压与真实电流仍由电机动态和控制环联系。

报告还联系了 HAL 的比较值宏，但没有实际移植或配置结果。default 设置三路 duty 为零已作为兜底逻辑解释，不能当作功率级已经断开的实物保护结果。
