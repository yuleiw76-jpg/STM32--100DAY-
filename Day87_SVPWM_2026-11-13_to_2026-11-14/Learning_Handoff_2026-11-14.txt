## 二、昨日主要学习内容

### 1. 三相逆变桥的开关状态

重新理解了三相逆变桥的A、B、C三个桥臂。

每个桥臂有上、下两个功率开关。

采用理想互补开关逻辑：

- 1：上管导通，下管关断。
- 0：上管关断，下管导通。

三个桥臂共有8种开关状态，其中6个为非零电压矢量，2个为零电压矢量。

手册采用的状态编号：

| 矢量 | ABC开关状态 |
|---|---|
| U0 | 000 |
| U1 | 001 |
| U2 | 010 |
| U3 | 011 |
| U4 | 100 |
| U5 | 101 |
| U6 | 110 |
| U7 | 111 |

理解了U4、U6不是两路电压，而是**同一个三相逆变桥的两种整体开关状态**。

例如：

- U4（100）：A接母线正端，B、C接母线负端。
- U6（110）：A、B接母线正端，C接母线负端。

注意：这里描述的是桥臂相端电位，不等于绕组对浮动中性点的相电压。

### 2. 为什么SVPWM要优化开关顺序？

手册指出：

从U4（100）切换到U0（000），只有A相桥臂需要改变状态。

从U4（100）切换到U7（111），B、C两个桥臂都需要改变状态。

因此，在其他条件相近时，前一种切换通常有较少的开关损耗。

理解了：

**SVPWM不只是计算每个电压矢量持续多久，还需要合理安排状态之间的切换顺序。**

第一扇区常见的对称开关序列：

000 → 100 → 110 → 111 → 110 → 100 → 000

在这个顺序中，每次状态改变最多只需要切换一个桥臂。

它也能够形成中心对称的三相PWM波形。

### 3. 为什么明明只有两个有效电压矢量，却还需要ABC三相？

曾经混淆：

计算T1、T2时只涉及两个有效矢量，因此误以为逆变器实际输出的是两路电压。

后来理解：

**两个有效电压矢量，不等于两相电压。**

SVPWM使用相邻两个非零电压矢量，加上零矢量，通过时间加权合成目标平均电压矢量。

但每一种电压矢量都对应ABC三个桥臂的一组开关状态。

真实电机始终是三相系统。

### 4. T1、T2、T0的物理意义

之前已经学习过作用时间公式，昨日继续结合实际开关状态理解：

- T1：当前扇区起始方向的有效电压矢量作用时间比例。
- T2：当前扇区结束方向的有效电压矢量作用时间比例。
- T0：两个零矢量合计的时间比例。

满足：

\[
T_1+T_2+T_0=1
\]

其中，T1、T2、T0在代码中是归一化的时间占比，不是实际秒数。

特别纠正了一个容易混淆的问题：

在第二扇区（60°～120°）中：

- T1对应60°方向。
- T2对应120°方向。

虽然T1公式使用的是目标角度与120°边界的夹角，但T1实际对应60°矢量。

用户通过自己画矢量分解图，理解了这一几何关系。

后续教学应统一使用“扇区起始方向”和“扇区结束方向”，避免用“前边、后边”造成歧义。

## 三、昨日最重要的理解突破：T1/T2与Ta/Tb/Tc的关系

这是昨天反复讨论、最后真正想通的核心问题。

### 1. 最初的疑惑

用户提出：

“我们最终是通过控制100、110、111这些开关状态各自的持续时间来控制平均电压方向，为什么程序却要计算ABC三个桥臂各自为1的时间占比？”

这个问题并非不理解STM32不能直接输出U4/U6，而是质疑：

**为什么电压矢量作用时间要转换为三个桥臂的占空比？转换之后是否还能保证原来的电压矢量作用时间？**

### 2. 最终理解的答案

关键在于STM32使用了**中心对齐PWM**。

当ABC三个通道使用相同的周期、正确的PWM模式及极性，并让高电平以周期中心对齐时：

只需要设置ABC三个通道的高电平持续时间，就能够自动形成预期的开关状态切换顺序。

例如第一扇区：

\[
T_1=0.3,\quad T_2=0.4,\quad T_0=0.3
\]

程序计算：

\[
\begin{cases}
T_a=T_1+T_2+T_0/2=0.85\\
T_b=T_2+T_0/2=0.55\\
T_c=T_0/2=0.15
\end{cases}
\]

即：

- A相占空比85%。
- B相占空比55%。
- C相占空比15%。

由于三个PWM波形居中，可以反过来恢复各个开关状态的总时间：

\[
T_{100}=T_a-T_b=30\%
\]

\[
T_{110}=T_b-T_c=40\%
\]

\[
T_{111}=T_c=15\%
\]

\[
T_{000}=1-T_a=15\%
\]

完全恢复原来的作用时间。

**最终理解：Ta、Tb、Tc不是替代T1、T2、T0的控制目标，而是把同一组开关时间转换为STM32定时器可以执行的占空比。**

用户最后自己总结：

“我们是采用中心对齐，只要算出来ABC各自高电平持续时间，就自动对齐控制各个桥开关了。”

这是昨日最重要的学习突破。

## 四、完整阅读FOC_SVPWM函数

昨日开始逐行理解手册的SVPWM代码，最终读完了整个函数。

函数入口：

```c
void FOC_SVPWM(float Uq, float Ud, float angle)
```

三个参数：

- Uq：q轴目标电压。
- Ud：d轴目标电压。
- angle：转子当前电角度，代码使用弧度。

### 1. 计算目标电压幅值

```c
float Uout = _sqrt(Ud * Ud + Uq * Uq)
             / VOLTAGE_LIMIT;
```

理解了：

\[
|\vec U_{ref}|=\sqrt{U_d^2+U_q^2}
\]

利用勾股定理计算dq轴电压矢量大小，再除以直流母线电压进行归一化。

注意：

Uout不是直接输出到某个桥臂的PWM占空比。

当Ud=0时，分子等于|Uq|，不是无条件等于Uq。

### 2. 计算目标电压矢量角度

```c
angle = _normalizeAngle(
    angle + atan2(Uq, Ud)
);
```

这一行曾重点学习。

理解了：

`atan2(y,x)`根据二维矢量的两个分量，计算矢量相对于横轴的方向角。

因此：

```c
atan2(Uq, Ud)
```

得到目标电压矢量相对于d轴的角度。

再加上转子的当前电角度，得到目标电压矢量相对于固定α轴的角度。

当Ud=0时：

- Uq大于0：相对角度为+90°。
- Uq小于0：相对角度为−90°。

特别纠正：

**新的angle不是电机下一步要转到的位置角度，而是SVPWM准备施加的目标电压矢量的方向角。**

归一化后的范围：

\[
0\leq angle<2\pi
\]

实际存储单位是弧度，而不是0～360的角度数值。

另外，这里描述的是目标**电压**矢量超前或滞后转子d轴90°，不能据此断言实际电流矢量也严格保持90°。

### 3. 判断扇区

```c
sector = floor(angle / _PI_3) + 1;
```

理解了：

- `_PI_3`就是π/3，对应60°。
- `floor`表示向下取整。
- `+1`将编号转换为1～6。

最终得到目标电压矢量所在的扇区。

### 4. 计算两个有效电压矢量的作用时间

```c
float T1 = _SQRT3 *
    _sin(sector * _PI_3 - angle) * Uout;

float T2 = _SQRT3 *
    _sin(angle - (sector - 1.0f) * _PI_3)
    * Uout;
```

理解了：

- T1使用目标电压与当前扇区结束边界的夹角，求起始矢量的时间比例。
- T2使用目标电压与当前扇区起始边界的夹角，求结束矢量的时间比例。
- 这些公式来自之前学习的矢量分解及SVPWM时间计算。

用户曾发现T1公式出现120°，却对应60°方向，因此提出质疑。

通过自行画图已经理解，不需要死记这个对应关系。

### 5. 计算零矢量时间

```c
float T0 = 1 - T1 - T2;
```

理解了T0是剩余的全部零矢量时间比例。

实际工程中应注意避免T0为负数，需要进行适当的电压限幅或过调制处理。

## 五、完整阅读switch的六个扇区

理解了：

```c
switch (sector)
```

根据目标电压所在扇区，选择对应的ABC三相占空比公式。

其中：

```c
float Ta, Tb, Tc;
```

分别保存三个桥臂状态为1的总时间占比。

### 六个扇区的有效电压矢量

| 扇区 | T1对应 | T2对应 |
|---|---|---|
| 1 | 100 | 110 |
| 2 | 110 | 010 |
| 3 | 010 | 011 |
| 4 | 011 | 001 |
| 5 | 001 | 101 |
| 6 | 101 | 100 |

手册采用两个零矢量000、111平分总零矢量时间的方案。

### 六个扇区的占空比公式

**第一扇区**

```c
Ta = T1 + T2 + T0 / 2;
Tb = T2 + T0 / 2;
Tc = T0 / 2;
```

**第二扇区**

```c
Ta = T1 + T0 / 2;
Tb = T1 + T2 + T0 / 2;
Tc = T0 / 2;
```

**第三扇区**

```c
Ta = T0 / 2;
Tb = T1 + T2 + T0 / 2;
Tc = T2 + T0 / 2;
```

**第四扇区**

```c
Ta = T0 / 2;
Tb = T1 + T0 / 2;
Tc = T1 + T2 + T0 / 2;
```

**第五扇区**

```c
Ta = T2 + T0 / 2;
Tb = T0 / 2;
Tc = T1 + T2 + T0 / 2;
```

**第六扇区**

```c
Ta = T1 + T2 + T0 / 2;
Tb = T0 / 2;
Tc = T1 + T0 / 2;
```

所有扇区的公式都可以通过检查开关状态中ABC哪些位为1，并累加相应时间来推导。

**用户不需要死记六组公式，理解第一扇区的推导后，已经具备理解其他扇区的基本方法。**

### default分支

```c
default:
    Ta = 0;
    Tb = 0;
    Tc = 0;
```

理解了这是非法扇区时的兜底处理。

但实际三相逆变桥中，设置占空比为0不等于断开功率级，因此不能直接当作完整的故障保护措施。

## 六、代码最后三行与STM32定时器的关系

```c
TIM_SetCompare1(TIM1, _PWM_RANGE * Ta);
TIM_SetCompare2(TIM1, _PWM_RANGE * Tb);
TIM_SetCompare3(TIM1, _PWM_RANGE * Tc);
```

理解了：

- Ta、Tb、Tc为0～1之间的占空比。
- `_PWM_RANGE`与TIM1的ARR设置相关。
- 三个计算结果分别写入TIM1的三个CCR寄存器。
- 定时器负责自动生成对应的三相PWM。

与此前学习的STM32 HAL库知识联系起来：

```c
__HAL_TIM_SET_COMPARE(
    &htim1, TIM_CHANNEL_1, valueA);

__HAL_TIM_SET_COMPARE(
    &htim1, TIM_CHANNEL_2, valueB);

__HAL_TIM_SET_COMPARE(
    &htim1, TIM_CHANNEL_3, valueC);
```

实际使用时仍要正确配置：

- 中心对齐PWM模式。
- 输出极性。
- 互补PWM。
- 死区时间。
- 功率驱动器使能及保护。
- CCR预装载和合适的同步更新时机。

这些属于后续真实硬件实现内容，不应认为已经实际完成。

## 七、昨日学习中的关键认知变化

### 1. 从电压矢量理解到真实硬件执行

之前知道两个基本电压矢量按不同时间比例可以合成目标平均电压。

昨天进一步理解了：

**理论上的矢量作用时间，怎样经过Ta/Tb/Tc计算，最终转变为TIM1三个PWM通道的CCR值。**

这连接了SVPWM数学算法与STM32实际硬件执行。

### 2. 理解中心对齐PWM的重要性

之前使用过普通PWM，知道ARR、CCR和占空比的关系。

昨天进一步理解了：

多个中心对齐PWM波形能够通过边沿之间的时间差，形成预定的三相逆变桥开关状态序列。

因此CPU不需要手动逐次切换100、110、111等状态。

**SVPWM负责计算，TIM1定时器硬件负责按配置执行。**

### 3. 能够主动发现解释中的问题

学习时多次主动质疑：

- 两个有效电压矢量为什么对应ABC三相？
- T1为什么使用扇区结束角度，却对应起始矢量？
- 既然要控制各个状态的时间，为什么程序计算的是三个桥臂各自为1的时间？
- 这些时间换算成占空比后，能否保证原本的矢量作用时间？

这些问题最终都通过几何分析、开关状态分析和实际PWM图得到解释。

说明用户已经不满足于记住公式，开始追究数学计算如何落实到硬件行为。
