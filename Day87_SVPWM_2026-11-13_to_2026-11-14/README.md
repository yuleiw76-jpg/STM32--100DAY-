## 连起来的数据与开关过程

```text
d/q 电压指令、转子电角度
  → 目标电压幅值与固定坐标下方向
  → 所在扇区及两个相邻有效矢量
  → T1、T2、T0 时间比例
  → Ta、Tb、Tc 三个桥臂的占空比
  → 按定时器计数范围换成 CCR1/CCR2/CCR3
  → 按已配置的模式生成三相 PWM
```

这里最后一步是对定时器执行机制的学习，尚无真实配置或电机运行证据。电压指令与实际电流的动态关系、电流 PI 与限幅保护要结合后续工程验证。

## 关键理解

- U4(100) 和 U6(110) 是同一三相桥的两种整体状态；使用两个有效矢量不意味着实际只用两相。
- 第一扇区可用 000→100→110→111→110→100→000 的对称顺序，每次相邻转换只改变一个桥臂。
- 同周期、同中心、正确模式及极性下的居中高脉冲，可以将 Ta/Tb/Tc 的边沿间隔还原为各整体状态的作用时间。
- 算例 T1/T2/T0=0.3/0.4/0.3 得到 Ta/Tb/Tc=0.85/0.55/0.15，恢复 100=30%、110=40%、111=15%、000=15%。这是讨论中的示例，未记作全部由用户独立计算。
- 代码 T0 是两种零状态合计比例；教材时序图另用 T0/T7 分别指 000/111，需对齐记号。
- T1 对应扇区起始方向，T2 对应结束方向。第二扇区的几何关系有用户自行画图的交接记录。
- Uout 是电压幅值相对母线的归一化，Ta/Tb/Tc 才是三路 duty。Ud=0 时幅值分子为 abs(Uq)。
- 输入 angle 是转子电角度；加 atan2(Uq,Ud) 后变为目标电压相对 α 轴的方向，按弧度归一化。该计算不代表实际电流必然与转子保持固定 90°。
- 六个 switch 分支按各状态中 A/B/C 为 1 的时间累加。无需把记熟所有公式当成理解的唯一标准。
