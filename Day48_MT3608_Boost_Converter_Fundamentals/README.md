## 一、Boost 升压的基本过程

### 1. SW 断开

刚接通输入时，5V可以经过电感和肖特基二极管给输出电容预充电，因此不能简单理解成“SW断开时完全没有电流”。

### 2. SW 导通：电感储能

内部开关接通后，电流路径为：

```text
5V输入 → 电感 → SW → GND
```

SW节点接近0V，而输出电容已经保持一定的输出电压，因此二极管反向截止。电感电流不会突变，而是按下式逐渐上升：

```text
di/dt = Vin/L
```

这一阶段，输入电能转化为电感磁场能量，输出负载主要由输出电容暂时供电。

### 3. SW 关断：电感向输出送能

SW关断后，电感仍要维持原方向的电流，于是电感两端电压极性改变，把SW节点电压抬高，直到肖特基二极管正向导通。

此时电流路径为：

```text
5V输入 → 电感 → 二极管 → 输出电容与负载 → GND
```

输入电源和电感共同向输出端提供能量，电感电流逐渐下降。芯片不断重复“导通储能、关断送能”，从而获得高于输入电压的输出。

## 二、为什么能够稳定在12V

12V不是由“电感刚好产生7V”一次性得到的，也不是等待电感电流达到物理最大值后再关断。真正决定输出电压的是FB闭环，其中 `R30=19kΩ`、`R31=1kΩ` 对输出进行分压：

```text
Vout = 0.6V × (1 + R30/R31)
     = 0.6V × (1 + 19k/1k)
     = 12V
```

FB脚持续与芯片内部约0.6V参考电压比较：

- 输出低于12V：增加后续周期传递的能量；
- 输出高于12V：减少后续周期传递的能量；
- 输出接近12V：维持动态平衡。

理想连续导通状态下，Boost关系为：

```text
Vout = Vin/(1-D)
```

5V升到12V时，理想占空比约为58.3%。实际电路还存在二极管压降、MOSFET导通损耗、电感电阻和负载变化，因此由反馈环路自动修正，输出只能稳定在12V附近，而不是没有任何纹波的绝对12V。

## 三、芯片什么时候关断SW

MT3608采用固定频率的电流模式控制，开关频率约为1.2MHz。每个周期开始后，电感电流逐渐上升；芯片根据输出反馈产生本周期需要的峰值电流目标，达到目标后关断开关。

需要区分三种“最大电流”：

1. **正常工作峰值电流**：由输入电压、负载、占空比和反馈控制共同决定；
2. **芯片开关限流值**：用于过流保护，不是正常工作时每个周期都要达到的目标；
3. **电感饱和电流**：电感本身允许的上限，选型时应高于预期峰值电流。

如果负载过重、输入功率不足或电感进入饱和，即使反馈要求继续升压，输出也可能无法达到12V。

## 四、12V为什么不会马上下降

输出电容单独供电时，12V确实保持不了很久，其下降近似满足：

```text
ΔV ≈ Iload × Δt / C
```

但正常工作时，1.2MHz对应的开关周期约为0.83μs。输出电容刚向负载释放一小部分能量，后续开关周期就会再次通过电感和二极管补充能量，所以输出只产生较小纹波。

## 五、C27、C28和C29的作用

### C27：22μF输出储能与滤波电容

C27连接在 `+12_UP` 与GND之间：

- SW导通、二极管截止时，暂时给负载供电；
- SW关断、二极管导通时，接收电感传来的能量；
- 减小输出纹波和负载变化引起的电压波动。

可以说它利用“电容电压不能突变”稳定二极管输出侧，但更准确的表述是：**C27负责维持和滤平12V输出节点**。

### C28：10μF输入缓冲电容

C28连接在VCC5输入端，负责就近提供较大的脉冲电流，减小供电线路阻抗导致的输入压降和中低频波动。

### C29：104高频去耦电容

`104=100nF`。C29为开关边沿产生的高频电流提供短而低阻抗的回路，抑制高频尖峰向输入电源线扩散。布局时应尽量靠近MT3608的IN与GND引脚。

```text
C28：缓冲输入端较大的变化
C29：旁路输入端快速的高频尖峰
C27：储能并稳定12V输出
```

## 六、今日重要纠错

1. 电容两端的**电压**不能突变；电感中的**电流**不能突变。
2. 电感储存的是磁场能量，不是一个固定的“7V电压”。
3. SW关断后，电感电压会调整到足以使二极管导通，而不是提前保证 `5V+7V=12V`。
4. MT3608依靠FB闭环不断修正输出，而不是一次升到12V后停止工作。
5. 输出12V只在器件参数、输入功率和负载均未超过设计范围时成立。
