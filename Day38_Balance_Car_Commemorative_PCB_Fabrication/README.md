# Day38_Balance_Car_Commemorative_PCB_Fabrication

## 今日成果

今天围绕已经完成双环 PID 调试的两轮平衡小车，设计并提交了一块纪念版 PCB。

这不是功能电路板，而是一张接近名片尺寸的纪念卡，用来记录第一代平衡小车在 Day37 成功站立的时刻。本次纪念板使用免费打样资格下单，当前等待审核、生产和收货。

## 设计主题

纪念板以简洁的两轮平衡小车线稿为主体，保留第一代原型车的两轮、底板、立柱与控制板等主要结构，并加入以下内容：

- `STM32 > 100 DAYS`
- `FROM BREADBOARD TO BALANCE`
- `DAY 37 -- I CAN STAND UP!`
- 完成日期：`2026.08.22`
- 阻尼振荡波形，代表小车由摆动逐渐趋于稳定的控制过程
- GitHub 项目二维码
- 金色外框、车体线条和装饰元素

## 制作过程

本次主要完成了：

1. 确定接近名片大小的长方形板框；
2. 简化平衡小车图案并调整正面排版；
3. 处理正反面文字方向和镜像显示；
4. 加入阻尼振荡波形与 GitHub 二维码；
5. 使用阻焊开窗与铜层组合实现蓝色板面上的金色图形；
6. 在 3D 预览中检查板框、图案、文字和正反面效果；
7. 使用免费打样资格提交纪念板订单。

## 今日收获

这块纪念板把前 37 天的学习成果转化成了一件可以长期保存的实物。从面包板、杜邦线、MPU6050、编码器和 PID 调试，到最终让小车站起来，纪念板记录了第一阶段项目真正完成的节点。

通过这次设计，也实际接触了 PCB 图形层、阻焊层、金属效果、背面镜像、二维码、板框与 3D 预览等非电气类 PCB 设计方法。
