## 一、CD4051是什么

CD4051B是一个单路 `8:1`、双向模拟多路复用/解复用器，可以理解为一个由数字信号控制的电子旋转开关。

```text
一个公共端COM
八个通道Y0～Y7
三根地址线A、B、C
一根总关闭控制线INH
```

它能够让八个通道中的一路与公共端导通，但不会放大信号，也不会增强驱动能力。通道和公共端均为双向端口，因此既能把八路中的一路送到公共端，也能把公共端送到指定的一路。

## 二、地址线与真值表

截图中STM32信号与芯片地址脚的对应关系为：

```text
A0 = A，最低位
A1 = B
A2 = C，最高位
```

当 `INH=0` 时：

| A2(C) | A1(B) | A0(A) | 选通通道 |
| ---: | ---: | ---: | --- |
| 0 | 0 | 0 | Y0 |
| 0 | 0 | 1 | Y1 |
| 0 | 1 | 0 | Y2 |
| 0 | 1 | 1 | Y3 |
| 1 | 0 | 0 | Y4 |
| 1 | 0 | 1 | Y5 |
| 1 | 1 | 0 | Y6 |
| 1 | 1 | 1 | Y7 |

当 `INH=1` 时，所有通道关闭，A/B/C的状态不再影响结果。

截图把INH直接接地，表示芯片永久使能。A0、A1、A2前的三个10kΩ是串联电阻，不是上下拉电阻；MCU复位时若GPIO处于高阻态，地址输入仍可能不确定。更稳妥的设计应增加默认上下拉，或在地址初始化完成前保持INH为高。

## 三、VDD、VSS与VEE

| 引脚 | 含义 |
| --- | --- |
| `VDD` | 正电源，也是模拟信号允许范围的上边界 |
| `VSS` | 数字控制逻辑的0V参考，通常接系统GND |
| `VEE` | 模拟信号允许范围的下边界，可接GND或负电源 |

模拟信号正常工作范围为：

```text
VEE ≤ Vsignal ≤ VDD
```

单电源示例：

```text
VDD = 3.3V
VSS = 0V
VEE = 0V
允许模拟信号约为0～3.3V
```

要传递 `-2.5V～+2.5V` 信号，可使用更稳妥的双电源示例：

```text
VDD = +3.3V
VSS = 0V
VEE = -3.3V
```

此时STM32的A/B/C/INH仍然输出普通的0～3.3V逻辑电平，不需要输出负电平。

### 截图勘误

- 第三张截图中的完整引脚表实际属于 `CD4052B`，不是CD4051B；不过7脚VEE、8脚VSS和16脚VDD在两者中相同，所以该段电源结论没有因此改变。
- 截图使用 `VDD=+2.5V、VEE=-2.5V` 的例子不够稳妥。当前TI数据手册明确给出的双电源范围为±3V～±10V，正式设计应以具体厂商和版本的数据手册为准。

## 四、截图测试电路的两路输入

测试电路只使用Y0和Y1：

```text
A2 A1 A0 = 000 → Y0：CD_TEST直接输入
A2 A1 A0 = 001 → Y1：CD_IN经过分压后输入
```

Y1前的900kΩ和100kΩ组成十分之一分压：

```text
VY1 = VIN × 100k / (900k + 100k)
    = VIN / 10
```

理想关系为：

| 输入电压 | 分压节点电压 |
| ---: | ---: |
| 10V | 1V |
| 20V | 2V |
| 25V | 2.5V |
| 30V | 3V |
| 33V | 3.3V |

## 五、为什么不能直接宣称安全测量33V

33V经过理想分压正好得到3.3V，但没有给以下因素留下余量：

- 分压电阻误差；
- 3.3V供电误差；
- 输入浪涌和过冲；
- TVS的击穿、钳位和漏电误差；
- 模拟开关输入范围；
- 0402高侧电阻的最高工作电压。

`SMBJ3.3A`中的3.3V通常表示反向工作电压，并不表示超过3.3V就会精确钳位到3.3V。必须锁定厂家和完整料号，核对 `VRWM`、`VBR`、`VC`、漏电和结电容。

更合理的设计应让最大输入只映射到约3.0V，并通过软件校准实际分压比例。900kΩ两端在33V输入时约承受29.7V，也必须核对0402电阻的额定工作电压，必要时把高侧电阻拆成多只串联。

## 六、CD4051不是理想导线

真实模拟开关存在：

- 导通电阻；
- 关闭漏电；
- 通道和公共端寄生电容；
- 控制信号切换带来的瞬态扰动；
- 不同通道之间的串扰。

常见的“125Ω导通电阻”是较高供电电压下的典型条件，不能直接套到3.3V。TI数据手册在5V、25℃条件下给出的导通电阻约为470Ω典型、1050Ω最大；3.3V下不能假定更好。

因此CD4051只能称为“选通或断开通道”，不能称为电气隔离器。关闭通道仍可能通过漏电和寄生电容耦合信号。

## 七、高阻分压与ADC采样

900kΩ/100kΩ分压节点的等效输出电阻为：

```text
RTH = 900k || 100k = 90kΩ
```

这个阻抗较高。STM32 ADC内部采样电容需要经过分压器和CD4051重新充电，因此切换通道后立即读取，第一次结果可能仍混有旧通道的电压。

推荐采样流程：

```text
设置A/B/C选择目标通道
→ 等待模拟节点建立
→ 丢弃第一次ADC转换结果
→ 再采样一次或多次
→ 根据需要求平均
```

改善方法包括：

- 延长ADC采样时间；
- 切换后增加等待时间；
- 降低分压电阻；
- 在CD4051与ADC之间增加合适的电压跟随器；
- 根据实际速度和精度要求选择现代低导通电阻、低漏电模拟开关。

CD4051具备“先断后接”功能：切换时先断开旧通道，再接通新通道，避免两个输入短暂相连。但公共端会短暂高阻，这不能替代软件等待和重新采样。

## 十、安全事项

- 本电路没有电气隔离，测试源必须与电路正确共地；
- 不用于市电或未知共模电压；
- 在保护器件、电阻误差与额定工作电压未核对前，不进行33V满量程测试；
- 不使用未确认规格的TVS作为精密3.3V钳位；
- 带电调整前先设置电源限流，并从低电压逐步验证；
- 不进行负电源实验，除非已确认电源极性、公共参考和所有器件的允许范围。
