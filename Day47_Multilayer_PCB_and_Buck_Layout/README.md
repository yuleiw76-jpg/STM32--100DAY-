## 一、四层 PCB 的基础认识

四层 PCB 的价值不只是“多了两层可以走线”，更重要的是可以获得较完整的参考平面和更连续的电流回流路径。常见的入门层叠方式可以理解为：

```text
L1 Top：元器件、关键信号和必要的功率走线
L2 Inner1：尽量完整的 GND Plane
L3 Inner2：电源平面或部分信号
L4 Bottom：普通信号和辅助连接
```

元器件仍然只能焊接在 Top 或 Bottom。内层主要用于铜平面、信号走线和电源分配，通过过孔与外层连接。

今天开始建立的关键认识是：PCB 不能只检查“信号有没有从 A 到 B”，还要考虑电流从 B 返回电源的路径。高频电流的去程与回程越靠近，形成的回路面积越小，通常越有利于降低噪声和 EMI。

## 二、Altium Designer 中的几个常见提示

### 1. Room Definition Violation

原理图同步到 PCB 后，Altium Designer 可能自动生成 Component Room。如果器件被移到 Room 外部，就会显示绿色违规标记。

在不需要按 Room 分区的学习工程中，可以删除自动生成的 Room。绿色高亮不一定代表封装错误、短路或电气连接错误，应该先查看具体的 DRC 规则名称。

### 2. Un-Routed Net

Un-Routed Net 表示网络尚未完成布线。在布局阶段出现属于正常现象，但最终准备制板前应该逐项处理并重新运行 DRC。

### 3. Silk To Solder Mask

该提示表示丝印文字或丝印线距离焊盘、阻焊开窗过近。学习布局时可以暂时集中处理电气连接，但真正制板前仍应调整丝印并满足工厂规则。

## 三、Buck PCB 首先按照能量流向布局

TPS5430 与 LM2596 的外围结构虽然不同，但基本功率路径相似：

```text
输入接口
  → 输入电容
  → Buck 芯片
  → PH/SW 开关节点
  → 电感
  → 输出电容
  → 输出接口或负载
```

因此布局时应先摆放功率器件，再考虑普通信号和板面是否整齐。正确的优先级不是“看起来对称”，而是让关键电流路径短、宽、紧凑。

## 四、为什么 D1 要紧贴芯片

续流二极管 D1 并不是串联在芯片与电感之间，而是从 PH/SW 节点连接到 PGND/GND 的续流支路：

```text
芯片 PH/SW ──●── 电感输入端
              │
             D1
              │
          PGND/GND
```

芯片关断时，电感电流不能突变，D1需要迅速导通，为电感电流提供续流路径。D1中的电流会随着开关状态快速变化，因此它与 PH/SW、PGND 之间的路径过长时，寄生电感更容易造成尖峰和高频干扰。

所以官方布局通常让 D1比电感更贴近芯片。但这里真正比较的不是两个器件中心到芯片的直线距离，而是：

- D1到 PH/SW 的连接是否很短；
- D1到 PGND/GND 的返回路径是否很短；
- 芯片、D1与输入旁路电容形成的高频回路面积是否足够小。

电感也应靠近 PH/SW，只是 D1的高频换流回路具有更高的布局优先级。

## 五、SW 节点为什么不能盲目铺大铜

PH/SW 节点会在高、低电位之间快速跳变，属于高 `dv/dt` 噪声节点。过大的铜面积会增加它与周围线路之间的寄生耦合，并使其更容易向外辐射干扰。

因此布局原则是：

```text
PH/SW 到 D1、电感输入端：短、足够宽、面积不过度扩大
```

铜皮需要满足载流能力，但不能把 SW 节点无意义地铺成大面积铜区。

## 六、电感输出端为什么可以使用宽走线

经过电感以后，电流变化已经被平滑，输出端不再是高速跳变的 PH/SW 节点。因此从电感输出端到输出电容，可以使用一条短而宽的功率走线，也可以根据实际需要使用局部铜区，并不强制整片铺铜。

这条连接承担完整的负载电流，所以不能使用普通的细信号线。实际线宽应根据最大电流、铜厚、允许温升和线路长度计算，而不能仅凭截图中的视觉宽度决定。

今天的 LM2596 布局中，已经把电感输出端到输出电容正极的线路加宽，并缩短了连接路径。

## 七、输入电容、输出电容与反馈线

### 输入侧

小容量陶瓷电容负责处理快速变化的高频电流，因此应该最靠近芯片 VIN 与 GND。大容量输入电容用于提供较慢的能量缓冲，可以紧跟在小电容后面。

### 输出侧

输出电容应靠近电感输出端，使电感、电容与负载之间的电流路径短而直接。小电容负责高频旁路，大电容负责储能和缓冲较慢的输出变化。

### 反馈侧

FB/VSENSE 只负责检测输出电压，电流很小，可以使用较细走线。它应该从输出电容正极附近的稳定输出节点取样，并远离 PH/SW、D1和电感等噪声区域。

功率线路与反馈线路的目标不同：

```text
功率线：短、宽、低阻抗
反馈线：短、安静、远离开关节点
```

## 八、今天实际完成的布局调整

在 TPS5430 和 LM2596 PCB 复刻过程中，今天完成或理解了以下调整：

1. 以芯片为中心安排输入电容、D1、电感和反馈网络；

3. 让电感输入端靠近同一个 PH/SW 连接点；

5. 避免继续扩大 PH/SW 铜皮；
6. 将电感输出端用短而宽的线路连接到输出电容；
7. 为后续从输出电容处引出 FB/VSENSE 采样线保留安静路径。

