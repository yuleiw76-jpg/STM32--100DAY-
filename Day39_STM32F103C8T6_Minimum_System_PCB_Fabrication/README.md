## 验证边界

完成下单只能证明生产文件已经进入制造流程，不能代表最小系统板已经能够正常运行。

后续还需要依次完成：

```text
收到裸板
  ↓
检查板框、钻孔、焊盘、阻焊和丝印
  ↓
焊接元件
  ↓
断电检查短路与极性
  ↓
限流上电并测量 3.3V 电源
  ↓
验证复位、BOOT、晶振和 SWD
  ↓
下载 LED 测试程序
```
