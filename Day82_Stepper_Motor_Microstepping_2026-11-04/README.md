# 第五章第二节 步进电机原理及细分驱动控制

## 整步、半步与细分

对两相四线步进电机，独立写出单相通电的整步顺序 A+ → B+ → A− → B−。半步在相邻整步之间加入双相通电状态，使合成磁场指向中间位置。自测时经提醒补出了 B− 与 A+ 同时通电的最后一个过渡状态。

对于整步步距角为 1.8° 的电机，独立算出 64 细分时每微步的名义指令角度为 0.028125°，并解释了从 A+ 向 B+ 过渡时 A 相电流减小、B 相电流增大。指令角度是按细分数计算的设计值，实际轴角需要测量。

## 双 H 桥与 TB6612

沿着 H 桥追踪绕组电流，理解了切换两组对角开关如何改变电流方向，以及同一桥臂上下管同时导通为何会形成直通。经讲解确认 VM 是电机驱动电源，VCC 是逻辑电源。AIN1/AIN2 选择 A 相方向，PWMA 调节该相的 PWM 占空比。

## STM32 例程与定时器

对照手册例程中的 USER/main.c、HARDWARE/PWM/pwm.c 和 HARDWARE/STEP_MOTOR/step_motor.c 阅读。独立区分 K1 的定步运行和 K2 的连续运行。TIM1 输出两路 PWM，TIM3 在连续模式下定时调用 roll(-1)，每次调用写入一组两相 PWM 比较值。

按例程的名义 64 细分设计，一圈有 200 个整步，对应 12,800 次微步更新。经纠正后，能区分每圈更新次数、每秒触发次数和每次触发间隔。计算时先用每圈更新次数乘目标转速（转/秒），再用定时器每秒计数拍数除以每秒触发次数，得到每次触发所需的计数拍数。
