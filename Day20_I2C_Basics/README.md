# 一、char与unsigned char(u8)

## 1. 字节与bit

计算机中：

- 1 Byte = 8 bit

一个bit只有两种状态：

- 0
- 1

因此8个bit可以产生：

2^8 = 256

种不同组合。


## 2. char与unsigned char区别

### unsigned char (u8)

范围：


0 ~ 255


因为8位全部用于表示数值。


### char

通常范围：


-128 ~ 127


最高位作为符号位。


在STM32开发中：

u8通常用于表示：

- 寄存器数据
- 通信数据
- 传感器读取数据

例如：

```c
u8 data;

表示一个8位数据。

二、C语言位运算

STM32底层开发大量使用位操作。

常见符号：

符号	含义
&	按位与
	
<<	左移
>>	右移
~	按位取反
^	按位异或
三、按位与(&)

规则：

两个bit同时为1，结果才为1。

例如：

5:
0101

3:
0011

5&3:

0001

结果：

1

常用于：

判断某一位状态
读取寄存器某个位

例如：

data & 0x20

表示只关注第5位。

四、按位或(|)

规则：

只要有一个bit为1，结果就是1。

例如：

0101
|
0011

=

0111

STM32中常用于同时配置多个GPIO：

GPIO_Pin_4 | GPIO_Pin_5

表示同时选择4号和5号引脚。

五、位移操作
左移 <<

例如：

1 << 5

表示：

将1向左移动5位：

00000001

↓

00100000

结果：

0x20

常用于生成某一位的掩码。

右移 >>

用于提取高位数据。

六、按位取反(~)

作用：

每一位翻转：

0 -> 1
1 -> 0

例如：

5:

00000101


~5:

11111010

注意：

在STM32中，~最常用于生成清零掩码：

data &= ~(1<<5);

表示：

只将第5位置0，其余位保持不变。

七、位编号理解

8位数据：

7 6 5 4 3 2 1 0

编号从右向左，从0开始。

例如：

第5位：

00100000

对应：

1<<5

也就是：

0x20
