## 三相绕组与电流回路

在星形接法中，三相绕组的一端在电机内部相连，另一端分别引出为 A、B、C。自测时自行判断出 A 接正、B 接负、C 悬空时 A 到 B 有电流，C 相无电流。经讲解补全回路，电流从 A 端经过 A 相绕组到公共点，再经 B 相绕组从 B 端流出。

独立判断了对称回流支路中的电流均分，以及电流反向后各相磁场分量与合成磁场方向也反转。还学习了多个物理线圈如何组成三相绕组、星形与三角形接法，以及三相端子接同一电源轨的含义。

## 合成磁场与六步换向

独立答出两支大小相等、夹角为 60° 的矢量相加后，合成方向在中间，与两支矢量各差 30°。也独立数出了一相悬空、另外两相分别接电源正负端的六种组合。讲解补齐了霍尔信号用于识别换向区间，以及六步之间的 60° 按电角度计。机械角与电角度的换算取决于转子的极对数。

## 工程比较

手册末尾的简化模型中，在相同供电电流下，合成磁场可以增大，绕组发热也可以增大。比较实际运行哪种方式更省电，需要在相同转速和输出转矩下比较输入功率。这部分已讲解，后续可用一道对比题检查理解。
