## 已讲公式与物理关系

电流形成定子磁场，转子角度决定它与转子磁场的相对关系。测量相电流和转子角度后，才能在相应模型下判断与控制转矩。手动转动电机先产生感应电压，电流还取决于外部回路。本节的波形分析采用理想正弦模型。

转子电角度为 θe = (p × θm) mod 2π。p 为极对数，θm 为机械角度。转子 d 轴相对固定 α 轴的电角度与定子磁场相对转子的夹角分别记录。

在 ia + ib + ic = 0 条件下，手册采用的等幅 Clarke 形式为 iα = ia，iβ = (ia + 2ib) / √3。2/3 缩放改变数学表示的尺度。

Park 变换使用转子电角度，d 轴沿转子永磁磁链，q 轴在本节正向约定下超前 d 轴 90°。

- id = iα cosθ + iβ sinθ
- iq = −iα sinθ + iβ cosθ

电流矢量与旋转坐标系同步、幅值和相对夹角保持恒定时，dq 分量可以恒定。本节以 id* = 0、调节 iq* 控制转矩，两路电流调节器工程中常用 PI。
