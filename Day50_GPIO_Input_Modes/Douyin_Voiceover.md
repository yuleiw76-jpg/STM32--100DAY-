# Day50 抖音口播

为什么STM32的一个GPIO引脚明明什么都没接，读出来却可能在0和1之间乱跳？

今天我学清楚了GPIO的四种输入模式。

第一种是浮空输入。它没有内部上拉和下拉，只有外部芯片主动输出明确的高低电平时，读取结果才稳定；如果信号断开，引脚就可能受到噪声影响。所以浮空并不等于默认低电平。

第二种是上拉输入，外部没有信号时默认读1。按键接GND时，松开读1，按下读0。我一开始正好把这两个状态说反了。

第三种是下拉输入，逻辑相反：默认读0，外部拉到3.3V后读1。

最后是模拟输入。它会关闭普通数字输入通道，把连续变化的电压交给ADC等模拟外设处理，从而减少数字电路对模拟测量的影响。
