## 一、GPIO输入的核心任务

数字输入模式的任务，是把引脚上的电压判断为逻辑 `0` 或 `1`，供程序读取。

关键不是只看模式名称，而是先判断：

1. 外部电路是否会主动输出明确的高、低电平；
2. 外部信号断开时，引脚需要默认保持 `0` 还是 `1`；
3. 需要读取数字状态，还是测量连续变化的模拟电压。

## 二、浮空输入

浮空输入没有启用内部上拉或下拉电阻，引脚主要由外部信号源决定。

适用场景：外部数字芯片会主动输出明确的 `0V` 或 `3.3V`，STM32只需要读取逻辑 `0/1`。

```text
外部信号主动驱动 → 可以使用浮空输入
外部信号断开或处于高阻态 → 引脚电平不确定
```

因此，**浮空不等于默认低电平**。没有稳定信号源时，读数可能受噪声影响而变化。

## 三、上拉输入

上拉输入通过内部弱电阻把引脚连接到 `VDD`。外部没有驱动时，引脚默认读取 `1`。

按键接地时：

```text
按键松开：内部上拉使引脚为高电平，读取1
按键按下：引脚直接接GND，读取0
```

这是一种低电平有效的按键接法。

## 四、下拉输入

下拉输入通过内部弱电阻把引脚连接到 `GND`。外部没有驱动时，引脚默认读取 `0`。

按键接 `3.3V` 时：

```text
按键松开：内部下拉使引脚为低电平，读取0
按键按下：引脚接到3.3V，读取1
```

这是一种高电平有效的按键接法。

上拉和下拉仍然属于输入模式，内部电阻只负责确定默认电平，并不是让GPIO主动输出高、低电平。

## 五、模拟输入

模拟输入用于 ADC 等模拟外设测量连续变化的电压。配置为模拟输入后，数字输入缓冲通道被关闭，不再把引脚电压当作普通数字 `0/1` 读取。

这样做可以避免模拟电压处于数字门限附近时，数字输入电路反复切换而增加功耗、噪声和测量干扰。

需要准确区分：

- 外部数字芯片主动输出高低电平：使用数字输入，通常可选浮空输入；
- 电位器、传感器等输出连续电压：配置模拟输入，并由 ADC 完成采样。

## 六、四种模式对比

| 模式 | 外部无驱动时 | 典型用途 | 关键风险 |
| --- | --- | --- | --- |
| 浮空输入 | 不确定 | 外部芯片主动输出数字信号 | 信号断开时可能乱跳 |
| 上拉输入 | 默认1 | 按键接GND、低电平有效 | 容易把松开和按下读数说反 |
| 下拉输入 | 默认0 | 按键接3.3V、高电平有效 | 外部上拉后逻辑会反转 |
| 模拟输入 | 不作普通数字判断 | ADC测量连续电压 | 不能当作普通数字输入使用 |

## 七、今日验收与纠错

1. 浮空输入在没有外部信号时不是固定的 `0`，而是不确定状态。
2. 上拉按键接GND时，正确逻辑是“松开读1，按下读0”。
3. 数字信号源主动输出明确高低电平时，应使用数字输入而不是模拟输入。
4. 模拟输入会关闭数字输入通道，减少数字电路对模拟测量的影响。
