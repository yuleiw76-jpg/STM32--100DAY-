## 一、反向击穿

PN 结反向偏置时，外加电场与内建电场方向相同，使耗尽层变宽、势垒升高，普通情况下只有很小的反向漏电流。

当反向电压继续升高并达到临界值后，强电场会使参与导电的载流子迅速增加，反向电流突然大幅上升，这种现象称为反向击穿。

击穿本身不等于器件立即损坏。真正可能烧坏器件的是没有限流，使电流和功率超过额定能力：

```text
P = U × I
```

只要电流、功率和温度保持在数据手册允许范围内，专门设计的器件可以工作在反向击穿区。

## 二、稳压二极管

稳压二极管也称齐纳二极管或 Zener Diode。它本质上仍然是 PN 结，但被设计成可以在规定条件下安全利用反向击穿。

典型接法为：

```text
VCC ── 限流电阻 ──┬── 输出
                   │
              稳压二极管
              阴极 K 在上
              阳极 A 接 GND
                   │
                  GND
```

稳压二极管进入击穿区后，电流变化很大，而两端电压只发生较小变化。输入继续升高时，稳压管电流增大，限流电阻上的压降也随之增大，因此输出电压能够维持在稳压值附近。

稳压值不是绝对不变，实际还会受到工作电流、温度、器件误差和动态电阻影响。

## 三、限流电阻与功率计算

不考虑负载时：

```text
R = (Vin - VZ) / IZ
```

教学算例：

```text
Vin = 9V
VZ  = 5V
IZ  = 10mA

R = (9V - 5V) / 0.01A
  = 400Ω

PR = (9V - 5V) × 0.01A
   = 0.04W
```

真实电路接入负载后，电阻提供的总电流会分成两部分：

```text
IR = IL + IZ
```

以上述 9V、400Ω、5V 稳压电路为例，电阻总电流为 10mA。如果并联一个 1kΩ 负载：

```text
IL = 5V / 1000Ω = 5mA
IZ = 10mA - 5mA = 5mA
```

限流电阻既要给负载供电，也要为稳压二极管保留足够的工作电流。若负载电流过大，使稳压管电流降到击穿区所需电流以下，输出将无法继续稳定在目标电压附近。

## 四、TVS 二极管的作用

TVS 的全称是 Transient Voltage Suppressor，即瞬态电压抑制二极管。它与稳压二极管一样利用反向击穿，但主要用于处理持续时间很短的浪涌、静电和高压尖峰，而不是长期稳压。

TVS 通常并联在被保护节点与 GND 之间：

```text
高压尖峰来源 ── 线路阻抗 ──┬── 被保护电路
                           │
                          TVS
                           │
                          GND
                           │
                     返回尖峰来源
```

正常工作电压下，TVS 基本不导通。高压尖峰使TVS两端电压达到击穿值后，TVS迅速形成低阻导电通路，大部分额外浪涌电流通过TVS进入GND回流路径，绕过被保护电路。

TVS不会凭空生成电流。分流电流由高压尖峰携带的能量推动，完整回路为：

```text
尖峰来源 → VCC节点 → TVS → GND回路 → 返回尖峰来源
```

GND是电流的公共低电位回流通路，不是让电流凭空消失的地方。

## 五、TVS 的关键参数

选择TVS时不能只看型号中的标称电压，需要区分：

| 参数 | 含义 |
| --- | --- |
| `VRWM` | 可长期承受且基本不导通的反向工作电压 |
| `VBR` | 开始明显反向击穿的电压 |
| `VC` | 指定浪涌电流下的最大钳位电压 |
| `IPP` | 指定脉冲波形下允许的峰值脉冲电流 |

通常满足：

```text
VRWM < VBR < VC
```

以 Littelfuse 的 `SMBJ5.0A` 为例：

```text
VRWM = 5.0V
VBR  = 6.4～7.0V
VC   = 9.2V（对应指定 IPP）
IPP  = 65.3A（10/1000μs 测试波形）
峰值脉冲功率 = 600W
```

`5.0V` 表示反向工作电压，不表示浪涌时会把节点精确锁定在 5.0V。指定浪涌条件下，节点可能升到约 9.2V。只要脉冲电流、持续时间和能量没有超过额定能力，TVS不一定损坏。

600W 是短时峰值脉冲能力，不是连续功率。若长期承受同等功率，结温会持续升高并导致器件烧毁。

- [Littelfuse SMBJ5.0A 产品页](https://www.littelfuse.com/de/products/overvoltage-protection/tvs-diodes/surface-mount/smbj/smbj5-0a)

## 六、单向与双向TVS

以SMBJ系列常见命名为例：

```text
SMBJ5.0A  → 单向TVS
SMBJ5.0CA → 双向TVS
```

保护固定为正电压的直流电源时，单向TVS通常采用：

```text
阴极 K → VCC
阳极 A → GND
```

这样正常工作时TVS处于反向截止状态，正向高压尖峰出现时才进入反向击穿。若接反，TVS会像普通二极管一样正向导通，无法按预期利用反向击穿，并可能产生过大的电源电流。

双向TVS可以近似理解为两个方向相反的TVS组合，适合交流线路或正负变化的双极性信号。

## 七、正向与反向偏置复习

记忆口诀：

```text
P正N负：正向偏置
P负N正：反向偏置
```

| 状态 | P区 | N区 | 外加电场与内建电场 | 耗尽层 | 电流 |
| --- | --- | --- | --- | --- | --- |
| 正向偏置 | 接正极 | 接负极 | 方向相反 | 变窄 | 明显增大 |
| 反向偏置 | 接负极 | 接正极 | 方向相同 | 变宽 | 漏电很小，击穿后骤增 |

二极管中，P区对应阳极A，N区对应阴极K。可以用 `P 接 Positive 等于正向偏置` 辅助记忆。
