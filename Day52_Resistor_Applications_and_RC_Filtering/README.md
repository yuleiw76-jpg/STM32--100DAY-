## 一、限流电阻

LED正向导通后，电流会随电压迅速增加。串联电阻承担一部分电压，并把电流限制在LED和GPIO能够承受的范围内。

基本公式：

```text
I = (VCC - VF) / R
R = (VCC - VF) / I
P电阻 = I²R
```

其中，`VF`是LED在当前工作电流下的正向压降，应以具体器件的数据手册或实测结果为准。

### 手册纠错

手册先说明普通硅二极管的典型正向压降约为`0.7V`，随后又用这个数值计算LED电流，这不够严谨。可见光LED的`VF`通常高于`0.7V`，并且会随颜色、型号、电流和温度变化。

例如假设红色LED的`VF=2.0V`，电源为`3.3V`，电阻为`220Ω`：

```text
I = (3.3V - 2.0V) / 220Ω ≈ 5.9mA
```

验收中还计算了：`5V`电源、`VF=2.0V`、目标电流`10mA`时，理论阻值为`300Ω`。在只有`270Ω`和`330Ω`可选时，选择`330Ω`，实际电流约为`9.1mA`，更接近安全侧。

LED直接接电源的主要风险是过流和过热，不应简单理解为“电压大就一定爆炸”。

## 二、电阻分压与ADC采样

上、下两个电阻串联，从中点取样时：

```text
Vout = Vin × R下 / (R上 + R下)
```

已知ADC端电压并需要还原输入电压时：

```text
Vin = Vout × (R上 + R下) / R下
```

### 24V电压检测

手册电路使用：

```text
R上 = 20kΩ
R下 = 1.3kΩ
Vin = 24V
```

因此：

```text
VPA1 = 24V × 1.3 / (20 + 1.3) ≈ 1.465V
```

如果输入升高到`27V`，PA1约为`1.648V`。设计分压电路时应该按照输入的最高可能电压检查ADC引脚是否安全，而不是只看标称电压。

### 电池电压检测

手册使用两个`10kΩ`电阻，因此分压比例为`0.5`：

```text
VBAT = 3.7V  → VADC1 = 1.85V
VBAT = 4.2V  → VADC1 = 2.10V
```

程序还原电池电压时应执行：

```text
VBAT = VADC1 / 0.5 = VADC1 × 2
```

例如ADC1测得`1.9V`，原始电池电压应为`3.8V`，不能再次乘以`0.5`。

### 关于“调整参考电压”

这里并没有改变STM32 ADC自身的参考电压，而是通过分压缩小输入信号的幅度。对于`2.5V±2.5V`的信号，其范围为`0～5V`；分压后让它落入ADC允许的`0～3.3V`范围，程序再按分压比例还原原始电压。

实际设计通常会为电源波动和电阻误差保留一定余量，不会刻意让最大输入恰好等于ADC上限。

## 三、电流采样电阻

在负载回路中串联一个很小的电阻，可以把电流转换成小电压：

```text
V采样 = I负载 × R采样
I负载 = V采样 / R采样
P采样电阻 = I负载² × R采样
```

手册中的采样电阻为`0.01Ω`。验收示例：

```text
I = 8A   → V采样 = 0.08V，P = 0.64W
V采样 = 0.06V → I = 6A，P = 0.36W
```

采样电压通常很小，实际电路常使用运算放大器放大后再送入ADC。采样电阻的额定功率也必须保留温升余量，不能只按计算值刚好选择。

不能直接使用`24V ÷ 0.01Ω`计算负载电流，因为电源电压主要加在负载上，采样电阻两端只有由负载电流产生的小压降。

## 四、电容放电电阻

放电电阻并联在电容两端。断开电源后，它为电容中的电荷提供泄放通路，避免节点长时间保留电压。

放电速度由时间常数决定：

```text
τ = RC
V(t) = V0 × e^(-t/RC)
```

手册中的参数：

```text
R = 100kΩ
C = 220µF
τ = 22s
```

放电时的近似规律：

| 时间 | 剩余电压 |
| --- | ---: |
| 1τ | 36.8% |
| 2τ | 13.5% |
| 3τ | 5.0% |
| 4τ | 1.8% |
| 5τ | 0.67% |

因此本电路约经过`5τ=110s`后，可以认为电容基本放完，但数学上并不是瞬间变成绝对零。

电阻越小，放电越快，但正常通电时功耗越大；电阻越大，正常功耗越小，但放电越慢。

## 五、RC低通滤波

基本RC低通结构为串联电阻、输出端并联电容到GND：

```text
输入 ── R ──┬── 输出
            │
            C
            │
           GND
```

低频和直流成分较容易保留；频率升高时，电容阻抗减小，高频噪声更多地被旁路到GND。

截止频率：

```text
fc = 1 / (2πRC)
```

截止频率并不是一堵墙。在`fc`处，输出幅值约为输入的`70.7%`；频率继续升高时，信号才会受到越来越强的衰减。

### 手册数值不一致

原理图标注的是：

```text
R5 = 22Ω
C7 = 1µF
```

按原理图计算：

```text
fc = 1 / (2π × 22Ω × 1µF) ≈ 7.23kHz
```

正文却代入`33Ω`和`1µF`，因此得到约`4.82kHz`。实际设计与计算前必须先统一原理图和BOM中的电阻值。

### 工程提醒

如果`22Ω`确实串联在LM2596的大电流输入路径上，还必须检查直流压降`IR`和功耗`I²R`。本次只确认了RC滤波原理，尚未确认该阻值在实际负载条件下是否合适。

## 六、五种应用的核心关系

| 应用 | 电阻完成的任务 | 核心公式 |
| --- | --- | --- |
| LED限流 | 限制支路电流 | `I=(VCC-VF)/R` |
| 电压分压 | 缩小待测电压 | `Vout=Vin×R下/(R上+R下)` |
| 电流采样 | 把电流转换成小电压 | `V=IR` |
| 电容放电 | 为储能提供泄放通路 | `τ=RC` |
| RC滤波 | 衰减高频噪声 | `fc=1/(2πRC)` |

## 安全提醒

- LED和GPIO支路必须限制电流；
- ADC引脚不得超过芯片允许的输入范围；
- 大电流采样电阻必须检查额定功率和温升；
- 断电后的电容仍可能保留电压，不能只凭“已经断电”判断安全；
- 电源路径中的串联电阻必须同时检查压降和功耗。
