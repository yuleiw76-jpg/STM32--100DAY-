## 复现实验范围

使用 STM32F103C8/STM32F10X_MD 与 ARMCC5 工程；实际芯片型号不符时先确认，不直接照搬下载设置。打开本包工程并 Rebuild，使用已验证的供电与 SWD 下载方式。

USB 转 TTL RX 接 PA9，GND 共地；本实验仅观察发送时这两根信号线即可。双向使用时 TX 接 PA10，保持 3.3V TTL 信号。USB 转 TTL 的 VCC 不与已有板子电源重复连接。串口设置 115200、8N1；LSI 无需外接低速晶振，按键和备份电池不是本次计时验证的必需条件。

首次切换配置会清除整个备份域，包括旧 RTC 时间和所有备份寄存器，并沿用示例日期 2024-04-01 16:29:00，不自动获取电脑当前时间。LSI 按约 40000 Hz 的标称值分频，未校准；显示毫秒字段不代表达到毫秒级准确度。不要用本版证明断电期间时间持续前进。

本包复制实际 LSI 学习副本的源码与工程，不收录旧构建缓存；main.c、rtc.c 作为原版对照保留但不参与当前目标编译。未加入讨论过的主循环临时 RTC_Get 调试行。原编译日志来自当天先前构建，不冒充本次归档重新编译的日志。
