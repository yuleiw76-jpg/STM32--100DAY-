# Day31_Balance_Car_Upright_Loop_P_Tuning

## 1. 今日学习内容

今天重新开始调试 STM32 两轮平衡小车的直立环，主要完成了机械平衡角确认、反馈方向检查和比例项 `P` 的初步调节。

当前小车使用 STM32F103、MPU6050 兼容模块、DMP 姿态解算、L298N 电机驱动和直流减速电机。现阶段只调直立环，速度环保持关闭，积分项 `I` 和微分项 `D` 暂时设为 0。

## 2. 当前控制结构

直立环当前使用的位置式 PD 形式：

```c
err = aim_pitch - Pitch;
pidp = P * err - D * gyro[1];
```

为了适配当前电机安装方向，电机调用使用：

```c
go((int)-pidp, 0);
```

当前调试阶段关闭速度环：

```c
pidv = 0.0f;
```

因此目前的目标是先让小车具备直立纠偏能力，而不是要求它长时间停在原地。

## 3. 机械平衡角确认

通过 Keil Debug 的 Watch 窗口观察 `Pitch`，小车在机械直立位置附近的角度约为：

```text
Pitch ≈ -8.56°
```

今天将目标角逐步调整到：

```c
aim_pitch = -8.53f;
```

目标角不能默认设为 0°，因为 MPU 模块的安装角度、车体重心和机械结构都会使实际机械平衡角产生偏移。

## 4. 纠偏方向验证

今天确认了车身倾斜方向与电机纠偏方向：

- 小车后倾时，车轮向前纠偏。
- 小车前倾时，车轮向后纠偏。
- 左右轮能够同步转动。

这说明当前直立环已经属于负反馈方向。若纠偏方向相反，继续增大 `P` 只会使小车更快倒下，因此调参前必须先验证方向。

## 5. P 项调试过程

今天对比例项 `P` 进行了逐步调节，后续重点测试参数为：

```c
P = 650;
I = 0;
D = 0;
aim_pitch = -8.53f;
```

在 `P = 650` 的实验中，小车已经能够产生明显纠偏，但短暂松手后仍会过冲并倒下，表现出缺少阻尼的特征。

当前直立环输出限幅为：

```text
-2000 ～ 2000
```

当 `P = 650` 时：

```text
2000 ÷ 650 ≈ 3.08°
```

这意味着角度误差超过约 3.08° 后，P 项就会达到输出上限。继续盲目增加 `P` 不会提高最大输出，只会使系统更早饱和并更容易出现快速过冲。

## 6. 视频实验分析

今天记录了一段约 38.6 秒的实物测试视频。视频中多数时间由手扶住车体，并进行了数次短暂松手实验。

根据实验现象，目前可以确认：

- 纠偏方向正确。
- 电机响应明显，P 项已经能够提供纠偏作用。
- P 项增大到 650 后，系统开始表现出过冲和振荡趋势。
- 当前主要问题不再只是 P 不足，而是缺少 D 项提供的角速度阻尼。

由于视频中手部干预较多，暂时不能仅凭本次视频准确判断小车的持续漂移方向。后续拍摄应尽量从侧面固定机位，并在扶到目标角后完全松手约 1 秒，以便区分振荡、目标角偏差和单方向漂移。

## 7. 今日结论

今天没有实现稳定直立，但已经完成了直立环调参前最重要的基础验证：

1. 确认机械平衡角约为 -8.56°。
2. 将 `aim_pitch` 调整到 -8.53°附近。
3. 确认 Pitch 方向、电机方向和左右轮同步关系正确。
4. 确认 `P = 650` 已能够产生明显纠偏。
5. 认识到继续增大 P 的收益有限，下一步应该加入 D 项抑制过冲。

## 8. 下一步计划

保持以下参数不变：

```c
P = 650;
I = 0;
aim_pitch = -8.53f;
```

下一次只调整 `D`：

```text
D = 1
D = 2
D = 3
D = 5
```

每次只修改一个参数，并记录：

- 是否仍然快速倒地。
- 振荡幅度是否减小。
- 电机是否出现高频正反切换。
- 小车是否能够短暂站立。
- 是否存在持续向前或向后的漂移。

如果加入 D 后振荡反而明显加剧，应立即恢复 `D = 0`，重新检查 `gyro[1]` 的方向，不能继续盲目增加 D。

## 9. 工程发布说明

当前平衡小车仍处于 PID 调参阶段，因此 Day31 只上传学习总结，不上传完整 Keil 工程。

等直立环、速度环和整车平衡效果完成实物验证后，再整理并上传最终完整工程，避免把尚未调通的中间版本当作可复现项目发布。

## 10. Learning Summary

今天最大的收获是理解了平衡小车调参不能只看参数大小，而要先依次确认传感器方向、纠偏方向、机械平衡角、输出限幅和实际振荡现象。

`P` 决定小车偏离目标角后纠偏的力度，但 P 过大或输出饱和不能代替阻尼。当前已经从“寻找能够纠偏的 P”进入“加入 D 抑制过冲”的阶段。
