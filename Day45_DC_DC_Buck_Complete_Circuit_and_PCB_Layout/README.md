## 一、Buck 降压的核心过程

Buck 芯片内部的功率开关在输入电压与关断状态之间高速切换。占空比决定一个周期内向后级传递能量的多少：

```text
D = Ton / T
理想情况下：Vout ≈ D × Vin
```

当输出电压低于目标值时，反馈控制会增大占空比，让每个周期传递更多能量；当输出电压高于目标值时，则减小占空比。真实输出并不是简单取 PWM 的数学平均值，而是由开关、反馈、电感、电容、二极管和负载共同形成的动态平衡。

## 二、开关导通时的电流路径

LM2596 内部功率开关导通时，输入电源向负载供电，同时使电感电流逐渐增加并储存磁场能量：

```text
+12V → VIN → LM2596 内部开关 → SW/OUT 节点
     → 电感 → 输出节点 → 负载 → GND → 输入电源负端
```

此时续流二极管处于反向偏置，不参与主要导电回路。

## 三、开关关断时的续流回路

内部开关关断后，被切断的是 `VIN → SW/OUT` 的供电通道。电感电流不能突变，因此电感释放磁场能量，并借助续流二极管维持原方向的负载电流：

```text
GND → 续流二极管 → SW 节点 → 电感
    → 输出节点 → 负载 → GND
```

在典型非同步 Buck 中，续流二极管的阳极接 GND，阴极接 SW 节点。开关导通时它反向截止；开关关断时 SW 节点电位下降，它正向导通，为电感提供完整而安全的续流路径，避免产生破坏性的高压尖峰。

## 四、电感与电容的分工

```text
电感：平滑电流，阻碍电流快速变化
电容：平滑电压，阻碍电压快速变化
```

电感满足：

```text
u = L × di/dt
```

电感量越大，同样电压下电流变化越慢，但不能盲目增大。电感过大会使负载变化时的电流响应变慢，可能造成输出电压暂时下跌或上冲，同时还会增加体积、直流电阻和动态调节压力。

输出电容满足：

```text
i = C × du/dt
```

电容并不是只在异常时工作，而是在每个开关周期内根据电感电流与负载电流之差持续充电或放电：

```text
iC = iL - iLoad
```

- 当电感电流大于负载所需电流时，电容充电；
- 当电感电流小于负载所需电流时，电容放电补充负载；
- 负载电流突然增大时，电感电流来不及立刻增大，输出电容先放电；
- 负载电流突然减小时，多余电流先给输出电容充电。

## 五、大电容与 104 电容为什么并联

手册电路中的 `220μF` 电解电容与 `104`（`100nF`）电容都并联在输出与 GND 之间，它们不是串联在主电流路径中。

- `220μF` 电容储能较多，主要缓冲持续时间较长的负载变化和较低频率的输出纹波；
- `100nF` 陶瓷电容寄生电感较小，在高频下能为噪声提供更低阻抗的本地回路，主要旁路高频尖峰和噪声。

电容对高频噪声阻抗较小，并不是因为“阻抗大才产生噪声”。高频干扰原本已经存在；电容只是让这部分交流分量优先在输出节点与 GND 之间形成短回路，减少它继续传播到后级电路。

## 六、反馈调节

FB 是反馈采样端，相当于芯片测量输出电压的“眼睛”：

```text
采样输出 → 与内部参考值比较 → 调整占空比 → 输出回到目标值附近
```

FB 只用于测量电压，输入电流很小，不承担负载功率。它对噪声非常敏感，如果开关节点的高速电压变化或功率回路的高速电流变化耦合到 FB，芯片可能把干扰误认为真实的输出变化，造成占空比抖动、纹波增大、过冲，甚至环路不稳定。

## 七、PCB 布局原则

Buck 电路的 PCB 不能只追求“连通”，还要控制大电流回路面积和敏感信号受到的干扰：

1. 输入电容、芯片、续流二极管、电感和输出电容尽量靠近并按能量流向布局。
2. 大电流功率走线应短而宽，以减小电阻造成的压降与发热，并降低寄生电感产生的电压尖峰。
3. 高频开关电流回路面积要尽量小，减少电磁干扰。
4. SW 节点电压变化快，铜皮不宜无意义地扩大。
5. FB 从输出电容附近的稳定输出点采样，走线短而安静。
6. FB 走线远离 SW 节点、电感、续流二极管和大电流回路，并按照芯片数据手册连接参考地。
7. 具体元件参数和布局优先服从所用芯片的数据手册与官方参考设计。

## 八、今日纠正的易错点

1. 输出电容不是只有在“电感来不及工作”时才工作，而是在开关过程中持续充放电。
2. 负载电流突然增大时，电容先放电补充电流；负载电流减小时，电容才吸收多余电流并充电。
3. `220μF` 与 `100nF` 电容是并联滤波支路，电流不是依次流过两个电容后再到负载。
4. 续流二极管不是把电感电流送去消耗掉，而是让电感在关断阶段继续以原方向为负载供电。
5. 功率线短而宽不仅是为了“降低噪声”，还为了减小 `I·R` 压降、`I²R` 发热和 `L·di/dt` 尖峰。
6. FB 线可以较细，但“细”不是主要目标；真正关键的是短、干净并远离开关噪声源。

## 九、手册示例器件认识

本节从手册中认识了下面这些器件及作用：

| 器件 | 主要作用 |
| --- | --- |
| LM2596-5.0 | 固定 5V 输出的 Buck 开关稳压芯片 |
| 68μH 电感 | 储存磁场能量并平滑输出电流 |
| SS54 肖特基二极管 | 在内部开关关断时提供续流路径 |
| 220μF/16V 电解电容 | 储能并缓冲较慢的输出电压变化 |
| 104（100nF）电容 | 旁路高频尖峰与噪声 |
| FB 反馈端 | 采样输出电压并参与闭环调节 |

这些数值属于本次手册示例。真正制作电路时仍需结合输入电压、输出电流、开关频率、纹波要求、饱和电流、ESR、耐压和芯片数据手册重新核对，不能只按名称照抄。
