## 一、单节锂电池的基础参数

对于手册中的常见 `4.2V` 体系锂离子电池：

```text
标称电压：3.7V
充满电压：4.2V
```

`3.7V` 是标称值，不代表电池工作时始终保持 `3.7V`；实际电压会随荷电状态变化。

不同化学体系的电压不同，例如磷酸铁锂和高压锂电池不能直接套用 `3.7V/4.2V`，必须查看电芯规格书和充电要求。

## 二、串联电压与容量

电芯串联时，**电压相加，mAh容量不变**。假设每节电池均为 `3.7V、2200mAh`：

| 组合 | 标称电压 | 充满电压 | 容量 |
| --- | ---: | ---: | ---: |
| 1S | 3.7V | 4.2V | 2200mAh |
| 2S | 7.4V | 8.4V | 2200mAh |
| 3S | 11.1V | 12.6V | 2200mAh |

三节 `2200mAh` 电池串联后仍是 `2200mAh`，不会变成 `6600mAh`。串联后增加的是电压和总能量；如果三节相同电池并联，容量才会相加为 `6600mAh`，但并联也需要满足电芯一致性与安全要求。

`mAh` 表示容量，不等于电池允许的最大充电或放电电流。理想化地说，`2200mAh` 表示以 `2200mA` 放电约一小时，但实际续航还会受到倍率、温度、老化和截止电压等因素影响。

## 三、TP4056的基本作用

`TP4056` 是用于单节锂离子/锂聚合物电池的线性充电管理芯片。它接收输入电源，并按照充电控制过程把电池充到约 `4.2V`。

必须记住：

- `TP4056` 只适用于 `1S` 电池；
- 不能用一颗 `TP4056` 直接给 `2S`、`3S` 或更高串数的电池组充电；
- 多串电池组需要与串数匹配、具备均衡和保护功能的充电方案。

## 四、关键引脚与状态

| 引脚 | 基础作用 |
| --- | --- |
| `VCC` | 充电输入电源 |
| `BAT` | 连接单节电池正极 |
| `GND` | 电路地 |
| `PROG` | 通过外接电阻设置充电电流 |
| `CHRG` | 正在充电状态指示，通常为低有效开漏输出 |
| `STDBY` | 充满状态指示，通常为低有效开漏输出 |
| `TEMP` | 电池温度检测输入；是否启用取决于实际电路 |
| `CE` | 芯片使能控制 |

手册电路中的状态判断为：

```text
正在充电 → CHRG有效
充电完成 → STDBY有效
```

`CHRG` 和 `STDBY` 为开漏输出，实际连接LED或送入MCU时需要按数据手册设计上拉或限流电路。

## 五、PROG电阻与充电电流

`PROG` 引脚外接电阻用于设定充电电流，基本方向是：

```text
RPROG增大 → 充电电流减小
RPROG减小 → 充电电流增大
```

截图资料中给出了 `1.2kΩ` 对应约 `1A` 的示例，但不同版本的原厂资料、兼容芯片和克隆芯片可能采用不同系数。当前官方修订资料中的典型换算值也可能与旧资料不同。因此，**具体的RPROG阻值和充电电流必须以手中芯片的准确型号、厂家和对应版本数据手册为准**，不能仅凭通用模块图片或旧公式决定。

充电电流还必须符合电芯允许的充电倍率。即使芯片能够设置为 `1A`，也不能不看规格就用 `1A` 给小容量电池充电。

## 六、TP4056不等于完整保护电路

`TP4056` 的主要职责是充电管理，它本身不等于完整的电池保护系统，不能代替所有以下功能：

- 过放保护；
- 负载过流保护；
- 短路保护；
- 多串电池均衡；
- 完整的负载电源路径管理。

实际产品通常还需要选择带保护的电芯、独立保护板或合适的电池管理方案。设计时还要关注线性充电产生的热量：输入电压与电池电压的差值越大、充电电流越大，芯片发热通常越明显。

## 安全提醒

- 不给未知规格、鼓包、破损或异常发热的电池充电；
- 不把 `TP4056` 用作多串电池组充电器；
- 充电电流必须符合电芯规格，并检查芯片和PCB温升；
- 实验充电时应有人看管，并使用可靠的电池、保护措施和限流电源；
- 本次没有进行带电实验，不能把原理理解当作实物验证结果。
