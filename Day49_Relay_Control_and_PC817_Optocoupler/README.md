## 一、继电器是什么

图中的电磁继电器不是纯电子开关，而是一个**由电信号控制的机械开关**。它主要由线圈、电磁铁、衔铁、弹簧和触点组成。

线圈未通电时，弹簧让衔铁保持在默认位置；线圈通电后，电磁铁吸引衔铁，使触点发生切换。

## 二、COM、NC和NO

- `COM = Common`：公共端；
- `NC = Normally Closed`：常闭端；
- `NO = Normally Open`：常开端。

```text
线圈未通电：COM—NC导通，COM—NO断开
线圈通电：  COM—NO导通，COM—NC断开
```

这里的“常开、常闭”都以**线圈未通电**作为判断基准，不能根据负载当前是否工作来判断。

## 三、为什么MCU不能直接驱动线圈

继电器线圈所需电流通常超过GPIO能够安全提供的电流，而且线圈关断时还会产生反向感应电压。因此GPIO只负责输出控制信号，Q1负责承担线圈电流。

Q1在这里是NPN低边开关：

```text
Q1导通：VCC → 继电器线圈 → Q1 → GND
Q1截止：线圈失电，触点回到默认状态
```

Q1控制的是线圈是否通电，并不直接选择NC或NO。真正完成触点切换的是继电器内部的衔铁。

## 四、本图为什么是低电平触发

这张具体原理图的输入电流路径为：

```text
VCC → R1 → PC817输入LED → LED1 → P0.8
```

当 `P0.8=0` 时，GPIO作为电流下拉端，PC817内部LED和LED1中都有电流，于是控制链依次动作：

```text
P0.8输出低电平
  → PC817内部LED发光
  → PC817输出光敏三极管导通
  → 电流经R2进入Q1基极
  → Q1饱和导通
  → 继电器线圈吸合
  → COM从NC切换到NO
```

当 `P0.8` 输出高电平时，输入回路两端缺少足够压差，PC817、Q1和继电器依次关断。

因此，手册中“高电平线圈通电、低电平线圈不通电”的通用描述不适用于这张原理图。继电器模块既可能高电平触发，也可能低电平触发，必须根据实际输入电路判断。

## 五、PC817和Q1的分工

`PC817`内部包含一个发光二极管和一个光敏三极管：

- GPIO侧用电流点亮内部LED；
- 输出侧的光敏三极管接收到光后导通；
- 两侧通过光传递状态，内部没有直接的导线连接；
- PC817负责信号传递，不能直接承担继电器线圈电流。

Q1负责电流放大和低边开关，真正承担线圈电流。R2用于限制Q1基极电流。

需要注意：光耦本身具有隔离结构，但要让整个电路实现真正的电气隔离，输入侧与输出侧还必须使用互不连接的电源和GND。如果两侧共用同一VCC或GND，就不能称为完整隔离。继电器触点侧与线圈侧则由继电器内部结构隔开。

## 六、续流二极管D1

继电器线圈本质上是电感。Q1从导通切换到截止时，线圈电流不能瞬间变为0，会产生较高的反向感应电压。如果没有保护，这个尖峰可能击穿Q1并干扰控制电路。

D1的正确连接方式是：

```text
阴极 → VCC/线圈上端
阳极 → Q1集电极/线圈下端
```

### Q1导通时

线圈下端接近GND，D1阴极电位高于阳极，因此D1反向截止，不影响正常线圈电流。

### Q1关断时

线圈为了维持原方向电流，会把线圈下端电位抬高，使D1正向导通，形成局部续流回路：

```text
线圈下端 → D1 → 线圈上端 → 线圈 → 线圈下端
```

线圈电流在回路中逐渐衰减，磁场能量被安全释放，Q1集电极的电压尖峰也受到限制。

如果D1方向接反，Q1导通时会出现：

```text
VCC → D1 → Q1 → GND
```

这相当于绕过线圈形成近似短路，可能烧坏D1、Q1或电源。

## 七、关于1N4148的纠正

`1N4148`是小信号高速开关二极管，不能只因为继电器切换频率不高，就判断它一定适合所有继电器。

小电流继电器可能可以使用1N4148，但仍需核对线圈电流、二极管脉冲电流能力和反向耐压。线圈电流较大时，应根据参数选择额定能力更合适的续流二极管。

## 八、两个LED的含义

- `LED1`串在PC817输入回路中，是低电平触发指示灯；
- `LED2`直接连接在VCC与GND之间，是模块电源指示灯，并不能证明继电器已经吸合。
