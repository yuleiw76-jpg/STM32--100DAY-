## 一、ACS712怎样测量电流

ACS712让被测电流流过芯片内部的低阻铜导体，再利用霍尔效应检测电流产生的磁场，最后输出与电流近似成线性关系的模拟电压。

主电流通路与低压信号侧在芯片内部电气隔离，但这不代表整块 PCB 天然满足高压安全要求。实际设计仍要检查爬电距离、电气间隙、连接器和布线。

## 二、关键引脚

| 引脚 | 作用 |
| --- | --- |
| `IP+`（1、2脚） | 被测电流正方向的流入端，两脚内部相连 |
| `IP-`（3、4脚） | 被测电流正方向的流出端，两脚内部相连 |
| `GND`（5脚） | 低压信号地 |
| `FILTER`（6脚） | 外接电容设置带宽和噪声水平 |
| `VIOUT`（7脚） | 与被测电流成比例的模拟电压输出 |
| `VCC`（8脚） | 芯片电源，典型为5V |

正方向定义为：

```text
IP+ → IP-
```

正向电流使 `VIOUT` 高于零点；反向电流使 `VIOUT` 低于零点。

## 三、零点、灵敏度与换算

5V供电时，零电流输出的标称值为 `VCC/2`，也就是约 `2.5V`，但实际零点会受到供电、器件偏差和温度影响。

| 双向量程 | 典型灵敏度 |
| --- | ---: |
| ±5A | 185mV/A |
| ±20A | 100mV/A |
| ±30A | 66mV/A |

基本换算关系为：

```text
VOUT = VZERO + 灵敏度 × I
I = (VOUT - VZERO) / 灵敏度
```

以±5A版本为例：

```text
0A   → 2.50V
+2A  → 2.87V
-2A  → 2.13V
```

量程越小，每安培产生的电压变化越大，通常越容易分辨。正确选型原则是：

```text
选择能够覆盖最大峰值电流的最小量程
```

例如电机正常电流3A、启动峰值8A时，应选择±20A版本，而不是会超量程的±5A版本。

## 四、5V输出接入3.3V ADC

截图电路使用电阻分压把ACS712的输出缩小到原来的 `0.66`：

```text
VADC = 0.66 × VOUT
```

因此STM32读到的是分压后的电压，反算时必须先除以0.66。对于±20A版本：

```text
I = (VADC / 0.66 - VZERO) / 0.1
```

如果直接使用ADC端的实测零点 `VZERO_ADC`，也可以写成：

```text
I = (VADC - VZERO_ADC) / (0.66 × 0.1)
```

本次验收示例：零电流时ADC实测为1.68V，工作时读到2.01V，则：

```text
ΔVOUT = (2.01 - 1.68) / 0.66 = 0.5V
I = 0.5 / 0.1 = 5A
```

## 五、零点校准

程序不应无条件把零点写死为2.500V。更可靠的流程是：

```text
确认负载没有电流
→ 连续采样多次
→ 求平均得到实际零点
→ 后续使用电压相对零点的变化量计算电流
```

需要更高精度时，还应使用已知电流校准增益，并分别评估供电、ADC参考、电阻误差、噪声和温漂。

## 六、去耦、FILTER与电压跟随器

截图中的两个 `104（100nF）` 作用不同：

- VCC旁的电容是电源去耦，用于稳定芯片供电；
- FILTER脚的电容用于限制带宽和降低输出噪声。

FILTER电容越大，读数通常越平稳，但响应也越慢。测平均电流可以加强滤波；若要捕捉短暂的启动峰值，则要保留足够带宽。

LM358电压跟随器不负责放大，也不提供电气隔离。它的主要作用是：

- 以高输入阻抗避免加载前级分压；
- 以低输出阻抗驱动ADC内部采样电容；
- 缓冲分压网络与ADC的动态采样负载。

因此，“删掉跟随器后效果完全一样”并不严谨。只有在采样速度较低、ADC采样时间足够长并经过误差验证时，才可能省略。

## 七、如何理解1.5%误差

手册将 `1.5%` 直接乘以量程，只能作为特定温度、满量程点和规定滤波条件下的示例，不能理解成：

- 任何电流点都固定误差这么多；
- 分辨率就是1.5%；
- 一定能够稳定分辨0.1A。

在小电流测量中，零点偏移、噪声、温漂和ADC误差可能比满量程增益误差更明显。

## 八、PCB与安全边界

- ACS712必须串联进负载回路，不能并接在电源两端；
- 两个IP+引脚应共同连接，两个IP-引脚也应共同连接；
- 大电流铜皮应短、宽，并避免焊盘、过孔或走线局部缩颈；
- “1A对应40mil”不是通用定律；载流能力还取决于铜厚、内外层、长度、允许温升、散热和环境温度；
- 芯片量程不等于PCB、连接器和导线都能安全承受相同电流；
- 初学验证应使用低压、限流电源和小电流负载，不直接测量市电、高能电池组或电机堵转电流。
