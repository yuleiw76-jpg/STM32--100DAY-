## 一、电调板的功能链路

电调通过六个 MOSFET 组成的三相逆变桥，把电池提供的直流电转换成驱动三相无刷电机所需的三相脉冲电压：

```text
电池 VBAT
  → 母线滤波与辅助电源
  → MCU 产生换相控制信号
  → 三相栅极驱动器
  → 六个 MOSFET 三相逆变桥
  → A、B、C 三相电机输出
```

反电动势检测网络向 MCU 提供三相电压信息，用于判断转子位置和换相时机；电池电压采样用于监测母线电压；UART 与指示灯用于调试和状态显示。

## 二、LM2596 两级电源

第一套电源先使用 `LM2596-5.0` 将 12V 降至 5V，再由 `AMS1117-3.3` 得到 3.3V：

```text
12V → LM2596-5.0 Buck → 5V → AMS1117-3.3 → 3.3V
```

- `68μH` 电感平滑电流并储存磁场能量；
- `SS54` 在芯片内部开关关断时提供续流路径；
- 大容量电解电容缓冲较慢的纹波和负载变化；
- `104` 陶瓷电容旁路高频噪声；
- TVS 并联在电源与 GND 之间，用于限制瞬态过压；
- LED 与限流电阻指示 3.3V 电源状态。

## 三、TPS5430 Buck 电源

第二套电源使用 `TPS5430`。主回路同样由开关芯片、续流二极管、电感与输出电容组成，输出电压由反馈分压电阻决定：

```text
VOUT → R14、R15反馈分压 → VSENSE
     → 芯片比较内部参考电压
     → 调节开关占空比
     → 稳定输出
```

`BOOT` 与 `PH` 之间的自举电容为内部高侧开关驱动提供所需电压；`PH` 是高频开关节点，后续 PCB 中应让功率回路紧凑，并让反馈线远离该节点。

## 四、今日重要纠错

1. 复刻参考图时，应复制网络功能和极性，不能只复制器件的上下位置或引脚编号。
2. 不同器件库中的连接器可能采用不同引脚编号，必须同时核对符号、封装、实物标记和数据手册。
3. 电池本体通常不需要 PCB 封装，板上需要的是与电池线束匹配的连接器。
4. 没找到“锂电池封装”不影响今天完成原理图学习，但转 PCB 前必须放置两针电源接口并绑定正确封装。
5. 原理图看起来连通不代表可以直接上电，仍需完成编号、封装、ERC/DRC 和实物极性检查。

## 五、转 PCB 前的待修正项

截图检查发现以下项目尚需处理，因此当前状态是“学习复刻完成”，不是“已经验证可直接上电”：

1. `3.3V` 输出处的 D2 当前写成 `SMBJ5.0A`，应按参考图改为 `SMBJ3.3A`。
2. TPS5430 图中同时使用 `GND` 与 `PGND`；若没有明确的 NetTie/单点连接，它们在 EDA 中是两个不同网络。独立练习板可统一地网，或按数据手册明确连接。
3. TPS5430 示例中的自举、输入和输出电容不能仅凭截图照抄，转 PCB 前必须依据数据手册核对；输出端只有 `103` 不能充当完整的主输出滤波电容。
4. 当前页面仍有 `U?`、未完整注释的器件及重复位号，转 PCB 前必须执行 Annotate、Compile 与 ERC。
5. 图中的 `+12V` 应来自合适的 12V 电源或带保护的 3S 电池包；单节锂电池不能通过 Buck 降压得到 5V。
6. 若电路需要承载电机电流，应选择 XT60 或额定电流足够的端子，不使用普通 2.54mm 排针代替大电流电池接口。

参考资料：[TPS5430 数据手册](https://www.ti.com/lit/ds/symlink/tps5430.pdf)、[LM2596 数据手册](https://www.ti.com/lit/ds/symlink/lm2596.pdf)。
