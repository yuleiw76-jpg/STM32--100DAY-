# Day36_Balance_Car_Upright_PD_Verification

## 今日内容

今天继续调试 STM32F103 两轮平衡小车的直立环，主要通过 USB-TTL 串口采集 `Pitch`、`gyro[1]`、直立环输出和 PWM 数据，对不同的 `P`、`D` 参数进行短时间实物验证。

本日没有加入速度环，也没有复制完整工程。重点从“继续修改参数”转向“建立可信的测试方法”，确认哪些数据来自小车本身，哪些数据已经受到手扶、抓车和接线松动的影响。

## 当前状态

- 学习进度：练习中
- MPU6050 与 DMP：静态稳定性已验证
- 串口遥测：可以正常采集
- 直立环：出现过短时间小幅纠偏现象，但尚未完成无接触重复验证
- 当前阻塞：小车容易倾倒，面包板和 STM32 接触不牢，手扶会污染闭环数据

## 今日测试参数

经过多组参数对比后，本日最后用于微放手测试的参数为：

```c
static float P = 300;
static float I = 0;
static float D = 0.65;
float aim_pitch = 1.3f;
```

该参数只是当前测试基准，并不代表已经完成最终整定。

## 调试过程

### 1. 多组 PD 参数实验

今天依次尝试了不同的 `P`、`D` 组合，并通过串口统计以下数据：

- Pitch 最大值与最小值
- PID 输出达到 `±2000` 的比例
- Pitch 进入目标角 `±3°`、`±5°` 和 `±10°` 的时间比例
- gyro 变化范围

最初主要根据最大摆幅和 PID 限幅比例判断参数，但随后发现，小车倾倒后需要用手扶住，最大值和后半段数据已经不再代表小车自身的闭环响应。

### 2. 改进数据评价方法

只看最大误差不够严谨，只看平均值也可能产生误导。例如小车在 `-20°` 和 `+20°` 之间对称摆动时，平均值仍可能接近 `0°`。

因此后续评价改为同时观察：

- 中位数和最密集角度区间
- 10%～90% 分位区间
- 平均绝对误差
- 目标角 `±3°`、`±5°` 内的占比
- PID 限幅比例
- 放手后到误差超过 `3°`、`5°` 的时间
- 摆动幅度是否逐渐衰减

### 3. 识别手扶数据污染

一次五秒采集中，Pitch 最密集的区间为 `20°～22°`，占全部样本的约 43%，中位数约为 `20.21°`。

这并不表示小车围绕 `20°` 稳定，而是小车倾倒后被手扶在该角度，扶车数据占据了统计结果。由此确认：

> 手一旦接触车身，人就成为控制系统的一部分，该段数据不能用于评价直立环参数。

### 4. MPU6050 静态稳定性验证

在车身保持静止约三秒时，共采集约 205 组数据：

- Pitch 平均值：约 `-0.588°`
- Pitch 标准差：约 `0.337°`
- 90% 数据位于约 `-1.252°～-0.248°`
- gyro 绝对值中位数：约 `12`
- 未发现单次超过 `2°` 的 Pitch 跳变

这说明 MPU6050、DMP 和串口遥测在静止状态下工作稳定。此前的大范围角度变化主要来自车身运动、抓车动作和测试过程，而不是传感器持续随机跳变。

### 5. 微放手测试

在一次较完整的两秒微放手测试中观察到：

- Pitch 范围约为 `-4.19°～+3.90°`
- 平均绝对误差约为 `1.62°`
- PID 未进入 `±2000` 限幅
- 测试窗口内没有超过目标角 `±6°`

该结果说明 `P=300、D=0.65` 具备短时间小幅纠偏的可能，但后续重复测试受到手扶动作影响，因此目前只能作为实验现象，不能当作最终参数验证证据。

### 6. 接线问题

调试过程中出现过串口完全没有数据的情况，最后发现是 USB-TTL 与系统之间的 GND 连线松动。重新压紧连线后，串口数据恢复。

再次说明：控制系统调试前必须先保证供电、共地和信号连接可靠，否则软件参数分析没有意义。

## 今日结论

1. MPU6050 静态数据稳定，目前没有证据表明传感器本身故障。
2. 当前直立环已经出现短时间纠偏能力，但尚未完成可重复、无接触的落地验证。
3. 手扶、抓车和重新摆正会显著污染 Pitch、gyro 和 PID 数据。
4. 小车摔倒会撞松面包板、STM32 和 GND 接线，使每轮实验的硬件条件发生变化。
5. 在搭建防摔测试架前，继续反复修改 `P`、`D` 的价值有限。

## 明日计划

明天优先处理测试条件，而不是直接继续增加参数：

1. 加固 STM32、面包板、电源线、MPU6050 和 USB-TTL GND。
2. 制作松绳限位架，使小车在直立附近自由运动，倾斜约 `6°～8°` 后由绳子接住。
3. 双手只做安全保护，不主动接触车身。
4. 保持同一组参数完成至少三次可重复的短时间测试。
5. 根据分位区间、平均绝对误差、限幅比例和摆动衰减判断直立环。
6. 直立环验证完成后，再考虑恢复速度环和使用 Ozone 观察曲线。

## 安全与实验规范

- 调整接线和固定结构前必须断电。
- 不把保护绳系在 PCB、MPU6050 或杜邦线上。
- 小车直立时保护绳应保持松弛，不能持续拉动车身。
- 发现供电、GND 或面包板松动后立即停止调参。
- 在硬件状态不一致时，不比较不同参数的实验结果。

## Learning Summary

今天最大的收获不是找到了一组最终 PID 参数，而是认识到“采集到数据”不等于“数据可以用于调参”。

可靠的控制实验需要保持一致的初始角度、硬件连接和放手方式，还要排除手扶、抓车和接线松动造成的干扰。下一步先解决防摔和固定问题，再继续直立环验证，这样后续使用串口或 Ozone 得到的曲线才有比较价值。
